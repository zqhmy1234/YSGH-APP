# 忆光 - 企业微信接入指南

本文档详细说明如何将「忆光」个人AI记忆助手接入企业微信。

---

## 一、前置准备

### 1.1 企业微信管理后台配置

1. **登录企业微信管理后台**
   - 访问 https://work.weixin.qq.com
   - 使用管理员账号登录

2. **创建智能机器人**
   - 进入「应用管理」→「智能机器人」
   - 点击「创建机器人」
   - 选择「API 模式」
   - 填写机器人信息：
     - 名称：忆光
     - 头像：上传忆光logo
     - 简介：个人AI记忆助手

3. **获取机器人凭证**
   - 创建完成后，进入机器人配置页面
   - 记录以下信息：
     - **Corp ID**（企业ID）
     - **Corp Secret**（应用Secret）
     - **Token**（用于消息加解密）
     - **EncodingAESKey**（用于消息加解密）
     - **Bot ID**（机器人ID）

4. **配置消息接收模式**
   - 选择「长连接」模式（推荐，无需公网IP）
   - 或选择「URL回调」模式（需要公网域名）

### 1.2 企业微信群聊Webhook配置（用于主动推送）

1. **创建企业微信群聊**
   - 在企业微信中创建一个群聊
   - 群名称建议：忆光-记忆助手

2. **添加机器人**
   - 点击群聊右上角「...」
   - 选择「群机器人」→「添加机器人」
   - 创建机器人并获取 **Webhook Key**

## 二、环境配置

### 2.1 复制环境变量模板

```bash
cd /workspace/projects
cp .env.example .env
```

### 2.2 填写环境变量

编辑 `.env` 文件，填入实际的企业微信配置：

```bash
# 企业微信智能机器人配置
WECHAT_CORP_ID=your_corp_id
WECHAT_CORP_SECRET=your_corp_secret
WECHAT_TOKEN=your_token
WECHAT_ENCODING_AES_KEY=your_encoding_aes_key
WECHAT_BOT_ID=your_bot_id

# 企业微信Webhook配置（用于主动推送）
WECHAT_WEBHOOK_KEY=your_webhook_key

# 定时复盘配置（默认每天晚上21:00）
REVIEW_HOUR=21
REVIEW_MINUTE=0

# 数据库配置（Supabase）
SUPABASE_URL=your_supabase_url
SUPABASE_API_KEY=your_supabase_api_key
```

## 三、启动服务

### 3.1 安装依赖

```bash
cd /workspace/projects
uv sync
```

### 3.2 启动企业微信服务

```bash
# 方式一：直接运行
python src/main_wechat.py

# 方式二：使用uv运行
uv run python src/main_wechat.py
```

### 3.3 后台运行（生产环境）

```bash
# 使用nohup后台运行
nohup uv run python src/main_wechat.py > wechat_service.log 2>&1 &

# 查看日志
tail -f wechat_service.log
```

## 四、功能说明

### 4.1 消息接收与回复

用户在企业微信中发送消息后，忆光会自动：

1. **识别意图**
   - 记录记忆：自动识别并保存
   - 搜索记忆：查找历史记忆
   - 查看统计：获取记忆概览
   - 日常对话：友好互动

2. **自动处理**
   - 生成摘要
   - 打标签
   - 情绪识别
   - 分类归档

3. **回复确认**
   - 保存成功后回复确认信息
   - 包含分类、标签、情绪等信息

### 4.2 定时复盘

**执行时间**：每天晚上 21:00（可配置）

**复盘内容**：
- 今日记忆数量统计
- 情绪分布分析
- 重要记忆回顾
- 分类统计
- 感悟总结

**推送方式**：自动发送到企业微信群聊

## 六、常见问题

### Q1: 服务启动失败，提示缺少环境变量

**原因**：`.env` 文件未配置或配置不完整

**解决**：
1. 检查 `.env` 文件是否存在
2. 确认所有必填字段已填写
3. 重启服务

### Q2: 消息发送后没有回复

**原因**：WebSocket长连接未建立或配置错误

**解决**：
1. 检查企业微信机器人配置是否正确
2. 确认选择了「长连接」模式
3. 查看服务日志排查错误

### Q3: 定时复盘没有推送

**原因**：Webhook配置错误或当天没有记忆记录

**解决**：
1. 检查 `WECHAT_WEBHOOK_KEY` 是否正确
2. 确认当天有记忆记录
3. 查看服务日志

### Q4: 如何修改复盘推送时间

**解决**：
修改 `.env` 文件中的 `REVIEW_HOUR` 和 `REVIEW_MINUTE`：

```bash
# 改为每天早上8:00推送
REVIEW_HOUR=8
REVIEW_MINUTE=0
```
