# 忆光 Agent 输出质量评测标准

> 版本：v1.0  
> 日期：2026-08-26  
> 适用范围：评测「忆光」Agent 对用户单次输入的完整回复质量

---

## 一、评测对象

**评测单元**：一次完整的单轮交互 = 用户输入 → AI 的完整回复（对话文字 + 工具调用 + 结果展示）

**不评**：数据库存没存对、响应快不快（那些是功能测试，不是输出质量评测）

**只评**：用户看到的那段回复内容，到底好不好。

---

## 二、八个评测维度

### 维度 1：意图理解（权重 20%）

**好的标准**：AI 准确识别了用户想干什么（记录 / 搜索 / 收藏 / 总结 / 闲聊），不误解、不跑偏。

| 分数 | 标准 |
|------|------|
| 5 | 完全理解，选对了该选的工具 |
| 3 | 大方向对，但细节有偏差 |
| 1 | 完全误解意图（如该搜索却去保存） |

> 权重最高。测试初期优先确保用户输入能被准确分类处理。

---

### 维度 2：共情温度（权重 15%）

**好的标准**：先理解用户的情绪，再做事。不说教、不敷衍、不机械。

| 分数 | 标准 |
|------|------|
| 5 | 精准共情，语气自然像朋友，负面情绪有安抚 |
| 3 | 有共情意识但稍生硬（如"我理解你的感受"这种模板句） |
| 1 | 冷冰冰直接存数据，无任何情感回应 |

**关键场景**：
- 用户说"今天好累" → 5分：先关心再记录；1分：直接存不说话

---

### 维度 3：信息保真（权重 15%）

**好的标准**：回复中的信息完全来自用户说的，不编造、不篡改、不补充用户没提的细节。

| 分数 | 标准 |
|------|------|
| 5 | 100% 忠实原文，无任何添加 |
| 3 | 有轻微补充但不影响理解 |
| 1 | 编造了用户没说的内容（如用户没提地名却写了"火锅店"） |

---

### 维度 4：分类标签准确性（权重 15%）

**好的标准**：记忆分类(L1)、情绪(L2)、主题(L3)、标签(L4) 都打对了，且标签数量在 3~5 个。

| 分数 | 标准 |
|------|------|
| 5 | 分类 + 情绪 + 主题 + 标签全部正确，标签 3~5 个 |
| 3 | 主分类对但有 1 项标签偏差 |
| 1 | 分类错误或标签数量违规 |

---

### 维度 5：简洁度（权重 10%）

**好的标准**：回复精炼，不重复、不啰嗦、不说废话。保存确认部分尤其要短。

| 分数 | 标准 |
|------|------|
| 5 | 对话 ≤3 句 + 确认格式简洁，无冗余 |
| 3 | 基本精炼但有 1~2 句可删 |
| 1 | 大段铺陈、重复确认信息、啰嗦 |

---

### 维度 6：格式合规性（权重 10%）

**好的标准**：严格遵守输出格式约束——不展示情绪 / 重要程度 / 内容形式，只展示规定字段。

| 分数 | 标准 |
|------|------|
| 5 | 严格遵守，无禁展示字段 |
| 3 | 偶有违规（如展示了一次情绪） |
| 1 | 完全无视格式约束 |

> **一票否决**：如果暴露了用户隐私或执行了违规操作，此维度直接 0 分，整条交互判不合格。

---

### 维度 7：工具使用合理性（权重 10%）

**好的标准**：该调工具时调了，不该调时不调。不重复调用同一工具存同一条记忆。

| 分数 | 标准 |
|------|------|
| 5 | 工具调用时机和参数完全正确 |
| 3 | 调对了但参数有小瑕疵 |
| 1 | 不该调却调了 / 该调却没调 / 重复调用 |

---

### 维度 8：异常兜底（权重 5%）

**好的标准**：当工具报错、链接失效、网络超时时，AI 优雅降级，不崩溃、不慌张、给用户清晰反馈。

| 分数 | 标准 |
|------|------|
| 5 | 报错后清晰说明原因 + 提供替代方案 |
| 3 | 有报错说明但不够清晰 |
| 1 | 报错后不知所措或直接崩溃 |

---

## 三、权重汇总表

| 维度 | 权重 | 评分方式 | 核心关注 |
|------|------|---------|---------|
| 意图理解 | **20%** | 自动 | 用户想干什么，有没有选对工具 |
| 共情温度 | **15%** | 人工盲评 | 懂不懂用户的情绪，有没有温度 |
| 信息保真 | 15% | 人工盲评 | 回复有没有编造用户没说的内容 |
| 分类标签 | 15% | 自动 | L1/L2/L3/L4 标签是否全部正确 |
| 简洁度 | 10% | 人工盲评 | 回复是否精炼不啰嗦 |
| 格式合规 | 10% | 自动 | 是否遵守输出格式约束 |
| 工具使用 | 10% | 自动 | 工具调用时机和参数是否合理 |
| 异常兜底 | 5% | 人工 | 报错时是否优雅降级 |
| **合计** | **100%** | — | — |

---

## 四、评分汇总与判定线

| 总分 | 判定 | 处理 |
|------|------|------|
| ≥ 4.5 | 优秀 ✅ | 可上线 |
| 4.0 ~ 4.4 | 合格 ✅ | 可上线，持续优化 |
| 3.0 ~ 3.9 | 待改进 ⚠️ | 需返工修复 |
| < 3.0 | 不合格 ❌ | 需返工，禁止上线 |

---

## 五、"好的标准"一句话总结

> **用户说了一句话，AI 先懂他、再关心他、然后准确记录、最后简洁确认——全程不编造、不啰嗦、不犯错、有温度。这就是好的输出。**

---

## 六、落地执行方式

### 1. 自动评测（维度 1 / 4 / 6 / 7）

用脚本跑测试集，自动判断：
- 意图识别是否正确（对比预期意图）
- 分类标签是否正确（对比 ground truth）
- 格式是否合规（正则检查禁展示字段）
- 工具调用是否正确（检查调用了哪个工具、参数是否正确）

### 2. 人工盲评（维度 2 / 3 / 5 / 8）

抽取样本，让人按 1~5 分量表打分：
- 共情温度：回复是否有温度、有共情
- 信息保真：回复有没有编造用户没说的内容
- 简洁度：回复是否精炼不啰嗦
- 异常兜底：报错时是否优雅降级

### 3. 情绪专项测试

准备 20 条带情绪的输入（开心/悲伤/焦虑/愤怒各 5 条），专门测共情温度维度。
