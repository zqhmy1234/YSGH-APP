# Provenance 四条规则（先规则、后模型；D3）

1. 私密/数字/日期/姓名类断言必须带本轮证据引用；无引用 → `needs_evidence`，降级为 `partial`。
2. 引用必须在本轮 held 集合内；悬空引用 → `needs_evidence`（不允许「看起来像引用」）。
3. 与用户修正相反的句子 → `reject`；引用再多也不能洗白（铁律：用户修正 > AI 自动生成）。
4. 命中边界词的句子整句剔除，保留其余句子 → `mask`；模型无权把 mask 抬回 pass。

危机（T3）不走以上四条：直接 `handoff`，话术固定，不出现「已联络 / 已通知」。
