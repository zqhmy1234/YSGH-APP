> 前置：Sprint 4（M3）完成；客户端就绪（W15 硬约束——联调等最慢的一端）
> 后端资产已就绪：B4 同步 API（字段级 LWW/游标/软删除）+ 回响 + 搜索 + 分类 + 画像

## Sprint Goal

**M4 门禁**：端间同步一致；断电续传正确 → **M5 门禁**：数据安全全绿 + 测试清单 P0 全过 → 种子内测启动。

## Success Criteria

1. Android/Windows 端间同步一致（LWW/软删除/游标对账通过）
2. 断电续传正确（原图分片 + 断点续传，中断恢复不丢不重）
3. 数据安全全绿（密钥/传输/存储/备份演练）
4. 测试清单 P0（~60 项）全过
5. 种子包（APK 直装）分发，种子内测（15-30 熟人，验证输入习惯 Q1）启动

1. **S5-05 数据安全审计**（T1/T4）：与同步客户端（T2/T3）完全并行
2. **S5-02 Windows 同步**（T4）与 **S5-01 Android 同步**（T2/T3）：两端并行，共享 B4 API
