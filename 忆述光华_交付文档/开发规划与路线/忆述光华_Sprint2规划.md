## Sprint Plan: Sprint 2（M1 核心管线）

**Dates:** 2026-08-31（周一）— 2026-09-27（周日）｜**Team:** 用户（T1+T2 双线）+ Agent（虚拟队友）；T3/T4/P2/P3 待安排（到位则并行认领）
**Sprint Goal:** M1 门禁全绿 —— 事件聚合正式原型出正确率基线（AGG-001~008）、RAG 检索 Top3≥70% 且 P95<3s、SetFit 分类 ≥75%、ASR+护栏可用。

**Success Criteria:**
1. S2-01 事件聚合正式原型：Python 全量管线（预处理/L0/L1/L2/L3 + 增量）+ 500 张测试照片基准 + 端云阈值一致性（AGG-016）
2. S2-02 RAG 管线：Qdrant + BGE-M3（dense+sparse RRF）+ 查询路由/改写 + 双层 Rerank + 溯源 → **Top3≥70% + P95<3s（M1 门禁核心）**
3. S2-03 SetFit 5 类分类服务：训练 + 推理 API → 分类 ≥75%
4. S2-04 ASR 双通道 + 护栏：FunASR/SenseVoice + 百炼 qwen_response_check → 转写可用 + 护栏可用
5. S2-05 收尾：微信 code2session 真实接入（拿 key 后）+ COS STS 验证 + D7 正式结论文档（8/23）+ CI（GitHub Actions）
6. 团队供给线（若到位）：P3 标注数据 / P2 设计稿 W6 硬节点 / T3 DAO+UI / T4 服务器+合规跟进
