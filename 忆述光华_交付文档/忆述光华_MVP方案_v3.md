# 忆述光华 MVP 方案 v4 · 整合版（功能 + 技术栈 + 成本）

> 版本：v4.0｜日期：2026-11-19｜整理：技术部（海峰）
> v4 相对 v3 的**唯一实质变化**：第一层需求定位从"帮用户整理照片"纠正为"让记忆**找得到、看得回、可托付、有温度**"。
> 依据：v3.0（2026-08-14）+ 深度设计 B1-B5 九分支 + 15 格真实用户需求调研（见 `docs/真实用户需求调研_第一层纠偏_20261118.md`）+ 人话清单（`docs/需求清单_人话版_20261118.md`）。
> v3 原文已备份至 `docs/archive/需求文档旧版_20261119/交付文档/`。技术栈、成本、实现变更记录沿用 v3（未变部分不再重复，需要时看备份）。

## 〇、v4 改了什么（先看这条）

调研（15 个 Agent、带证据）证实：用户嘴上说"整理"，实际要的是"下次能秒找到 + 偶尔被回忆击中 + 信得过你"。82% 数字囤积、70% 照片拍完不再看、88.3% 收藏夹吃灰——痛点不在"存不下"，在"存了之后怎么办"。据此：

| 原 v3 表述 | v4 纠正 |
|---|---|
| F1"照片自动读取分类"领衔 | 定位改为"记忆可找回"，分类只是手段 |
| 去年今日 = P2 玩法 | 升为价值回路核心，但**必须配可控性**（屏蔽人/日期/词、一键关、雷区设置） |
| 用户愿上传云 AI 换整理 | 隐私是**前置门槛**：分级导入、端侧可验证、人脸声纹默认关 |
| 微表情/声纹识别情绪 | **删掉**（伪科学，真实数据失效）；"有人味"改靠回应语气 + 长期记忆 |
| 微信自动收+找 | 微信端收敛为**用户主动转发 + 后端微信客服**，不自动读聊天记录（合规红线） |
| 描述性搜索按四要素测 | 按口语碎片 query 测；保留经典搜索/时间轴降级出口 |

## 一、MVP 功能清单（v4 重排，F1-F9 保留编号便于对照）

| # | 功能 | 优先级 | v4 定位（纠偏后） |
|---|---|---|---|
| F1 | 照片自动读取与事件聚合 | P0 必有 | B3 四层事件（L0 瞬间/L1 日/L2 主题/L3 流）+ 多对多；**补"关系实体"层**（我和某某/我们那次）；自动归类、导入期确认、不在浏览时打扰；用户改过的算法永不覆盖 |
| F2 | 文字碎片输入 | P0 必有 | SetFit 5 类 + B5c 纠错；**用词说"精选/回忆"，不说"整理/清理"** |
| F3 | 语音输入 + AI 提炼 | P0 必有 | **一等公民**：按住即录一句话→自动转文字挂时间线（童言/老人口述）；FunASR 转写；情绪只做描述不做诊断，不给百分比 |
| F4 | AI 分类纠错 | P0 必有 | B5c 三层裁决；结果可解释、一键改、改完回"已记住你的选择" |
| F5 | 描述性搜索 | **P0 主入口** | B2：BGE-M3 + Qwen3-VL + LLM 路由 + 溯源；**分面理解口语碎片 + 多轮澄清 + 经典搜索/时间轴三级降级 + 命中理由展示**；Top3 门禁按"事件/记忆单元"和口语 query 测 |
| F6 | 微信入口（收+找） | P1 尝试 | **仅用户主动转发 + 后端企业微信客服（kf + msg_id 幂等）**；不自动读本地微信数据（合规红线） |
| F7 | AI 访谈式冷启动 | P0 优先玩法 | B1 三问；问答式引导（别给空白时间轴），尤其银发/老人端 |
| F8 | 时间轴展示 | P0 优先玩法 | 按事情串，不按文件日期平铺；**时间轴是"回忆仪式"，与搜索并存不可互替**；点结果跳当天 |
| F9 | Windows 桌面端 | **二期** | 08-26 已拍板移出 MVP，本版不列 |
| — | 回响机制（去年今日） | **P0 价值回路**（原 P2） | 默认克制（应用内展示、不推系统通知）；**可控性写进需求本体**：屏蔽人/宠物/词/日期段、单条不再显示、全局开关、雷区设置、推送时段用户定；中性文案禁"怀念吗" |
| — | AI 追问洞察 | P2 | B5b 护栏 + 情绪关怀 + Q40 频率；**先接住情绪→再谈事→建议需征求同意**；自伤伤人人工接管 + 求助渠道 + fail-safe（对齐网信办法） |
| — | 信任与掌控（v4 新增横切） | **P0 前置** | 首屏讲清本地/云边界；分级导入；人脸声纹默认 opt-in 可彻底删；只分析不训练不留人像；全量删除给回执；一键导出；隐私保险箱免费 |

## 二、技术栈（沿用 v3，未变）

云侧：PostgreSQL + Qdrant(named vectors) + BGE-M3 + Qwen3-VL-Embedding + qwen-flash/plus/long + 双层 rerank + SetFit + 百炼护栏 + FunASR/SenseVoice + 腾讯云 COS。
Android：uni-app x（Vue UI + UTS 能力层）+ ST-DBSCAN 端侧聚合 + WorkManager。
微信：企业微信客服 + UnionID。
> v4 技术侧唯一删减：**不做通用语音情绪模型、不做微表情识别**（详见纠偏表）。SenseVoice 情绪仅保留"相对描述"输出（"今天比平时低沉"），不做诊断/分类/打分。

## 三、100 用户成本（沿用 v3）

≈ 330-365 元/月，每用户 3.3-3.7 元；年度 ≈ 3,900-4,900 元。v4 无新增外部依赖，成本不变。

## 四、验收标准（v4 重写，吸收 v3 用户拍板项）

> 原 v3"产品部验收更新清单"里的 4 条硬性 + 6 条建议 + 3 条新增确认，用户已逐条拍板（原文里的"H：√ / 可以 / 暂定"）。这些拍板结论**全部保留**，下面按 v4 口径重排。

### 4.1 必须达标（硬性）

1. **找得到（F5）**：描述性搜索 Top3 ≥ 70%——query 集用大白话碎片句式（"有妈妈在、吃火锅那次"），按事件/记忆单元命中计；保留经典关键词搜索一键切换；搜不到反问或引导翻，不给空结果；Rerank 开/关两档口径分别记。
2. **回响可控（回响）**：屏蔽人/宠物/词/日期段、单条不再显示、全局开关、首次雷区设置——四项缺一不可；默认应用内展示不推系统通知；文案禁情感诱导。
3. **信任前置（横切）**：分级导入（不强制全相册）；人脸/声纹默认关可彻底删；删除给回执；一键导出；隐私保险箱免费。首屏可见边界说明。
4. **事件聚合（F1）**：L1 单日长事件不切碎、L2 主题流不混、照片/文字/语音混合聚合到同一时间线；**补关系实体层**；用户手动确认/合并/拆分后算法永不覆盖（v3 US-10 铁律，做成可见信任护栏）。
5. **稀疏记录（F1）**：一天 1-2 张并入日卡片（"8月14日 · 2张"），不造伪事件。〔v3 用户批"可以"〕
6. **时间错乱（F1）**：相机时间错的照片只标"时间存疑"不主动修正。〔v3 产品部已接受〕

### 4.2 体验与健康度

7. **语音一等公民（F3）**：按住即录→转文字→挂时间线；情绪只描述不诊断、可关可改可纠正、禁百分比。
8. **有人味（追问/关怀）**：先接住情绪→再谈事实→建议先问；禁"别想太多""你为什么这样"；让用户设 AI 性格（温暖/理性、语气、长短）；危机（自伤/伤人）人工接管 + 求助渠道 + AI 身份提示 + fail-safe。〔原 v3 第 5 条关怀文案库升级版〕
9. **低负担**：AI 自动归类零操作，严禁手动打标才能用核心功能；导入期确认、不在浏览时打扰。
10. **修正延迟认知**：qwen-flash 摘要 8-15 秒（可同步等），仅 3000+ token 长文才异步——对 v3 里"30-60 秒"的误写已纠正。〔v3 第 8 条〕
11. **后台纪律**：端侧 AI/事件聚合只在 WiFi + 插电 + 闲时跑，不常驻、不发热（防"图库吃掉大半电量"差评）。
12. **内测期零付费墙、零广告**：不拿付费挡用户数据（对冲 Day One/Moo 日记差评模式）。〔v4 新增〕

### 4.3 隐私与合规（v3 用户拍板 + v4 强化）

13. 照片原件默认上云 COS 可关闭；OCR/向量化/检测上传云厂商需如实写进隐私政策；Sentry 不含记忆内容；本地 SQLCipher。〔v3 第 9 条，用户批"暂定该方案"〕
14. 回响绝不触碰敏感记忆（分手/离世等），画像敏感校验 + 检测双查，进测试清单 SAF-006/007。〔v3 第 10 条〕
15. 隐私保险箱：用户自己可见（指纹/密码）；搜索不出现；回响不推送；导出单独打包。〔v3 用户拍板四条，全部保留〕

### 4.4 推送与内测节奏（v3 用户拍板保留）

16. 推送分策略：回响=in-app 不 push；每日复盘 22:00=push；语音处理完成=push；关怀=in-app 消息中心。〔v3 用户批 √〕
17. 内测节奏：先做最小内测——10 人左右、持续 14 天，搭一个具备"总结-查找"雏形的智能体，获取**真实输入数据、持续输入动力、使用体验**。〔v3 用户原话保留；v4 把 100 人画像配额与必问题写进 `docs/需求清单_人话版_20261118.md` 第八节〕
