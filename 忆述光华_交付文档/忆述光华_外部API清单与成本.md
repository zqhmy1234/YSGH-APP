## 二、各 API 详细清单（真实成本 + 官方网址）

### 1️⃣ 阿里云百炼 qwen-flash（LLM）

- **调用方**：后端服务（微信端摘要/分类、语音提炼、搜索 RAG、画像标注、今日摘要）
- **调用项**（收口后扩充）：
  - 微信端消息摘要/分类：9 万次/月 × 800 token
  - 语音提炼：3000 次/月 × 1200 token
  - 搜索问答：6000 次/月 × 800 token（含 **Query 改写** ~200 token/次 + **LLM 精排兜底**）
  - **LLM 任务路由**（TAP-RAG：文本/图片/任务类型分类，~100 token/次）
  - **画像枚举标注**（事件驱动，qwen-flash 映射到维度，低频）
  - 事件聚合 L2/L3 LLM 语义归并（qwen-flash 只看元数据）
- **真实成本**（官方计费，2026）：
  - 输入 **0.0002 元/千 token**（0.2 元/百万）
  - 输出 **0.0015 元/千 token**（1.5 元/百万）
  - 128K-256K 上下文：输入 0.0006 / 输出 0.006 元/千
  - 256K-1M：输入 0.0012 / 输出 0.012 元/千
- **月成本**：≈ 65 元（100 用户，含路由/改写/精排）
- **官方网址**：<https://help.aliyun.com/zh/model-studio/models>（计费：<https://help.aliyun.com/zh/model-studio/developer-reference/billing-for-tongyi-farui>）

### 2️⃣ 阿里云 FunASR（语音识别 + SenseVoice 情绪）

- **调用方**：后端服务（APP 语音输入转写 + 情绪标签）

- **真实成本**（官方计费，2026）：

- **月成本**：150 小时 × 0.79 ≈ **118 元**
- **官方网址**：<https://help.aliyun.com/zh/model-studio/paraformer>（录音文件识别；<https://ai.aliyun.com/nls>；SenseVoice：<https://funasr.com/blog/sensevoice-emotion-language-detection.html>）

## 三、云端服务器调研（2026-08 官方套餐）

### 3.1 需求分析（MVP 需要什么）

- 运行：FastAPI + RQ worker（SetFit/BGE-M3 推理）+ **Qdrant**（named vectors）+ PostgreSQL + Redis（AOF）+ 备份任务
- **内存是关键**：Qdrant 轻量（100K 向量 ≈ 128MB RAM）+ PG + BGE-M3（568M CPU int8）**4G 起步舒适，8G 宽裕**
- 带宽：100 用户内测，3-5M 足够（**照片上传走 COS STS 直传，不经服务器**，服务器带宽压力小）
- 推荐：**2核4G 起步，4核8G 更稳**（RQ worker 推理 + PG + Qdrant 同机）
- **Windows 端**：Zvec 嵌入式向量库（进程内），**不占服务器资源**
- **Sentry 走云版**（不自托管），不占服务器资源

### 3.4 推荐方案（按预算/场景）

| 场景 | 推荐 | 年成本 | 理由 |
|---|---|---|---|
| **MVP 内测最优（100 用户）** | 腾讯云 4核4G 秒杀 38 元/年 或 阿里云 2核4G 199 元/年 | 38-199 元 | 4G 内存够 Qdrant+PG+RQ worker；秒杀价白嫖一年 |
| **长期稳定（内测转正式）** | 腾讯云 2核4G 188 元/年（同价续费）或 阿里云 2核4G 298 元/年（续费同价） | 188-298 元 | 续费不涨，规避"首年便宜续费翻倍" |
| **宽裕档（跑本地推理）** | 腾讯云 4核8G 450 元/年 | 450 元 | SetFit+BGE-M3 同机跑，留余量 |

**⚠️ 关键提醒**：
1. **秒杀价只能买 1 台、仅个人新用户**——团队用企业认证账号则走企业档（合规但贵）
2. **别买 2核2G**：PG+Qdrant+RQ worker 同机内存紧张，2G 会频繁 OOM，省的钱不够折腾
3. **续费陷阱**：除"同价续费"款外，第二年续费是原价——长期用选"同价续费"款
4. **备案**：国内地域域名需备案（约 1-2 周，M0 启动），可先用 IP 访问内测或选香港地域（免备案，贵一点）
