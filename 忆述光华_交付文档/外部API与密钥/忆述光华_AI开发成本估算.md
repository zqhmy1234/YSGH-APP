# 忆述光华 · 开发部 AI 开发 Token 成本估算

> 生成：2026-08-16｜用途：AI 开发工具预算申请依据｜性质：**估算值**，价格以各厂商官方实时计费页为准（2026-08 市场价口径）
> 校准样本：本项目实测 —— 2026-08-16 单会话完成 Sprint 1 大半 T1 主线（认证/内容入库/测试/契约/备份，约 40 commits）；当前会话实测**缓存命中 91%**（332K 缓存 / 31K 新输入 / 4.1K 输出）→ Agent 场景大量上下文重读走缓存，**实际计费远低于原始处理量**

## 一、用量模型（按人/日，billed token = 实际计费的输入+输出）

| 角色 | 工作类型 | 每天 billed token | 说明 |
|---|---|---|---|
| 技术 4 人 | 深活日（Agent 编码/集成/联调） | ≈500K（输入 400K + 输出 100K） | 原始处理量 2-4M，缓存命中后计费约 1/5-1/8 |
| 技术 4 人 | 中活日（功能开发/文档/审查） | ≈260K（输入 200K + 输出 60K） | 按 60% 深活日 / 40% 中活日 折算 |
| 产品 3 人 | 浅活日（标注/文案/分析） | ≈40K | 聊天式辅助，量级远小于编码 |

**全队月用量**（22 工作日）：4 技术 ×（13×500K + 9×260K）≈ 35.4M ＋ 3 产品 × 22×40K ≈ 2.6M → **≈ 38M billed/月**

## 二、价格档位（元/百万 billed token，含输入 80% / 输出 20% 加权）

| 档 | 方案 | 输入单价 | 输出单价 | 综合有效单价 |
|---|---|---|---|---|
| A 全旗舰 | Claude Sonnet 4.5 / GPT-5 级 | ~21 元 | ~105 元 | ~38 元/M |
| B 混合（推荐） | 30% 旗舰 + 70% 国产中端（DeepSeek-V3.1 / Qwen3-235B） | — | — | ~13 元/M |
| C 经济 | 纯国产（DeepSeek / Qwen / 豆包；含本项目当前 deepseek-v4-flash） | ~1.5 元 | ~6 元 | ~2.5 元/M |

## 三、成本测算（38M billed/月 为基数）

| 口径 | A 全旗舰 | B 混合（推荐） | C 全国产 |
|---|---|---|---|
| 全队月成本 | 38M × 38 ≈ **1,440 元/月** | 38M × 13 ≈ **500 元/月** | 38M × 2.5 ≈ **95 元/月** |
| 22 周（5.5 月）总成本 | ≈ **7,900 元** | ≈ **2,750 元** | ≈ **520 元** |
| 技术岗人均年成本 | ≈ 4,000 元/人/年 | ≈ 1,400 元/人/年 | ≈ 270 元/人/年 |

## 四、订阅制替代（团队小 / 用量低时可能更划算）

| 方案 | 价格 | 适用 |
|---|---|---|
| GitHub Copilot Pro / 各家会员 | ~70-150 元/人/月 | 补全 + 聊天级辅助，产品岗够用 |
| Claude Max 档（重度 Agent） | ~700-1,400 元/人/月 | 用量 >150M billed/月 才划算，否则按量更省 |
| 国产会员（Kimi/豆包/通义） | 几十元/人/月 | 产品岗 + 轻量技术辅助 |

## 五、建议预算口径

1. 推荐 **B 混合档**：核心/疑难任务走旗舰 Agent，批量/常规任务路由到国产中端，配合缓存优化
2. 预算线：**500-1,500 元/月（全队）**，22 周约 3,000-8,000 元 —— 与项目本身云成本（约 4,000-5,000 元/年）同一量级，可控
3. 本项目当前 Agent 跑 deepseek-v4-flash（国产档），实际成本已落在 C 档区间，起步阶段几乎零压力
4. 调参：把"每天 billed token"与"单价"换成实际工具/用量即可重新乘算；技术岗扩到 N 人则月用量 ≈ 8.8M × N
