| 3 | **后端框架**（FastAPI / Spring Boot / NestJS / Go） | ✅ **已拍板：FastAPI + RQ/Redis + PostgreSQL**（2026-08-14 grill + 审计修正） | ⭐ 理由：后端 = AI 流水线编排器，AI 生态全在 Python（FunASR/SetFit/PaddleOCR/BGE/百炼 SDK）→ 后端 Python 直接复用 AI 代码零跨语言桥接；vibe coding 团队 Python 学习成本最低；FastAPI 30-40K req/s 支撑 10 万日活足够；全项目语言统一。**审计修正：Celery → RQ（Redis Queue）**——100 用户低频异步（每天几百次），Celery 的 beat/结果后端/复杂编排用不上、运维成本高 10 倍；RQ = enqueue + 独立 worker + PG 任务表记录状态，复用现有 Redis，vibe coding 团队维护成本最低。CPU 密集推理（SetFit/BGE-M3）走 RQ worker 独立进程，不阻塞 FastAPI 事件循环<br>**📈 升级路径**：任务类型变多（定时 beat/多 worker 分布式/结果后端）或任务量 > 几千/天 → **RQ → Celery**（迁移 = 替换队列库，任务函数签名不变）；需要长时间运行工作流/状态机 → **Temporal**（B5-c 共性纠错微调流水线复杂化时评估） |

| 5 | 代码规范 / 分支模型 | ✅ **已拍板：Git Flow 简化版**（2026-08-14 grill） | main + feature 分支 + PR 合并（main 保护），5 人以内团队够用 |
