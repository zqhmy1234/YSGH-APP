## 二、技术栈最终版（一句话全景）

```
前端   uni-app x 双轨（UI 层 Vue + 系统能力层自研 UTS 插件）→ 未来 iOS/鸿蒙/小程序
后端   FastAPI + RQ/Redis + PostgreSQL（28 表 10 域）+ Qdrant（named vectors）+ COS（STS 直传）
检索   BGE-M3 文本塔（dense+sparse）+ Qwen3-VL 图片塔（API，文字搜图）+ LLM 路由 + 双层 Rerank + 溯源
AI     FunASR/SenseVoice 双通道 + SetFit 分类 + qwen-flash 画像标注 + 百炼 Qwen3Guard 护栏
端侧   SQLite 插件（XView）+ 自研 DAO（迁移/加密/对账）+ ST-DBSCAN 四层事件聚合（UTS 原生）
Windows Electron + Python sidecar（PP-OCRv5 20MB + JSON-RPC 2.0 v1 + electron-updater）
微信   企业微信「微信客服」+ 消息回调幂等
同步   字段级 LWW + 软删除 30 天 + 离线队列（状态分级）+ WiFi 原图蜂窝缩略图
可观测 Sentry 云版双通道（崩溃+性能+日志）
```
