# 00 审计汇总 —— 8 页"当前代码 vs 原始设计稿 SVG"

审计日期：2026-08-30 · 审计方式：自写 SVG 解析器直接解析原始设计稿（含嵌套 transform 累积、fill-opacity、pattern 图片解析），逐区块与 .uvue 样式对比；设计稿文字已转曲，文字内容经渲染图核对。

**换算系数**：设计稿宽 390px ↔ 750rpx，**1 设计px = 1.923 rpx**（08 详情页画布为 390×1100）。代码 TabBar 组件用 px（1:1 设计px，仅 390pt 宽设备等比）。

## 一、根因：提取 JSON 全线损坏（最重要发现）

`design_data_for_agents/0X_*/design_data.json` **8 份全部解析失败**：

- `parse_error: "'Circle' object has no attribute 'r'"`（svgelements 库崩溃）
- 导致 `elements: []`（**0 条几何**）、`texts: []`（**0 条文字**）在所有页面一致出现；仅页面尺寸、defs 数量统计可用
- 另有两个系统性丢失：**fill-opacity**（设计稿大量使用 α.06–.65 的半透明色层）与**渐变方向**（设计稿多处为横向渐变）
- 结论：还原 Agent 实际是在**没有任何几何数据**的情况下靠截图目测还原的——数值偏差与结构猜测属必然，本次逐页抽查（每页 5 项）全部证实

## 三、共性问题（8 页横切）

1. **TabBar 组件（index/search/profile/messages 共用）整体偏离**
   - 底色：设计白色 α.55 毛玻璃+白描边 α.65+大阴影（dy10 blur14 α.098）→ 代码米色 `rgba(246,241,231,.85)` 无阴影
   - 图标 22px 比设计 15px **大 47%**；"时间轴""我的"图标 path 提取残缺（四边形/残弧，非罗盘/人形）
   - FAB "+" 号 28px vs 设计 15px；标签字号/颜色反而正确
2. **渐变方向系统性错误**：index/record/detail 的 hero 顶部暗化与底部溶解在设计稿中均为**横向**渐变，代码全部做成纵向；详情页相关卡缩略图渐变同样横向→纵向
3. **半透明色层体系（fill-opacity）还原不稳定**：搜索页/记录面板精确命中（α.12/.14/.10/.55 全对），但 TabBar 白 α.55、访谈问题卡 α.55、消息胶囊渐变、索引文字卡 α.10 面板均丢失——同一种设计语言时中时不中
4. **图标系统**：设计为统一琥珀/锈红细线矢量图标；代码混用 emoji（设置页）、错误图形（详情页心形）、残缺 path（TabBar）、偏大尺寸（详情页 ✦/返回箭头一倍）
5. **字号体系整体偏大 2-6rpx**：设计稿正文/元信息用 10.5-12.5px（20-24rpx）的小号层级，代码普遍 22-28rpx；页面主标题反而偏小（index"回忆"73rpx→48rpx）
6. **阴影参数普遍偏小**：设计大阴影 blur≈12-16px（23-31rpx）dy 3-10px，代码多为 16rpx/blur；浮起感弱
7. **结构性增删**：代码多出设计没有的模块（消息分段器+TabBar、搜索清除/麦克风、我的页品牌条+Beta、index 待确认区/回响卡等功能扩展），也有缺失（搜索大标题、消息返回导航、消息胶囊元信息）
8. **播放按钮配色**：设计"白圆+锈红三角"，index 做反（琥珀圆+白三角），搜索页做对——同一元素两页不一致
9. **自绘状态栏/Home 条**：设计稿含自绘 9:41 与电池，代码交给系统（合理，但整稿对照时首屏观感有差）
10. **文案漂移**：多处文案被功能化改写（搜索占位、我的页菜单项、消息卡片内容、空状态 CTA），设计的"记忆产品"语气（峰宝、回忆、去年今日）被稀释

3. index hero 区：文案/字号/头像/渐变方向按本审计 01 表逐项校正
4. messages 结构对齐：删分段器与 TabBar、加返回导航、恢复时间胶囊渐变面板、去掉行分隔线、拉开卡片间距
