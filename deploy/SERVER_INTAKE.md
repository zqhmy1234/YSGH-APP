# 服务器到货回报单（SERVER INTAKE）

> 生成：2026-09-23 ｜ 用途：买完服务器后填这张单发回，**即可直接开工**。
> 原则：**只收集「继续开发所需」的信息**——与开工无关的一律不写在这里。

## 怎么用

1. 在服务器上跑 **§C 的一键采集命令**，把输出整段贴回 → §B 就齐了。
2. 再补 **§A** 的几格（只有控制台能看到：公网 IP 与安全组规则）。
3. 密码 / 私钥**内容**不要写进这张单——§A 只填"用哪种方式"。

---

## §A 访问与网络 —— **阻断项**

| # | 字段 | 说明 | 填写 |
|---|---|---|---|
| A1 | **公网 IPv4** | 唯一阻塞客户端的一格（要填进 `config.uts` 的 `PROD_BASE_URL`） | `________________` |
| A2 | 公网 IP 是**固定/弹性**还是可能变 | 按量计费停机后 IP 常会变 → 客户端里写死的地址会失效 | `固定 / 可能变` |
| A3 | SSH 端口 | 默认 22 | `________________` |
| A4 | 登录用户名 | `root` / `ubuntu` / `ecs-user` … | `________________` |
| A5 | 认证方式（**只填类型，内容不要贴**） | 密钥对 / 密码 | `________________` |
| A6 | 私钥是否已放到本机 `~/.ssh/` | 是 → 我从本机直接驱动部署 | `是 / 否` |
| A7 | 安全组已放行 **22 + 8010** | 8010 没放行 = 客户端装上也连不上 | `已放行 / 未放行` |
| A8 | **5432 / 6379 / 6333 未对公网开放** | 依赖服务只绑 `127.0.0.1`；暴露即高危 | `已确认 / 有问题` |

## §B 机器与系统 —— **阻断项**（跑 §C 即得）

| # | 字段 | 为什么开发需要 | 填写 |
|---|---|---|---|
| B1 | 实例规格型号 | 回填核算确认 | `________________` |
| B2 | **CPU 核数 / 内存 GB** | 内存 **16G 是硬门槛**（常驻 9–11G + 推理峰值） | `____ 核 / ____ GB` |
| B3 | 系统盘 GB；数据盘（若有，含挂载点） | 部署路径与磁盘分账 | `________________` |
| B4 | 带宽 Mbps（写明**固定带宽还是按流量**） | 带宽核算是 5Mbps 前提的验收 | `____ Mbps / ____` |
| B5 | **地域 / 可用区** | 非中国内地会改变合规口径 | `________________` |
| B6 | **OS 发行版 + 版本** | 决定"系统准备"步骤（RUNBOOK 要 Python 3.11；Ubuntu 22.04 自带 3.10、24.04 自带 3.12） | `________________` |
| B7 | 架构 | 预期 `x86_64`（非 x86 影响模型 wheel） | `________________` |
| B8 | Docker / Compose / Python 版本 | 未装则需先装 | `________________` |
| B9 | 5432 / 6379 / 6333 / 8010 是否已被占用 | 端口冲突是已知坑 | `________________` |
| B10 | 是否纯净系统（有无预装 PG / Redis / nginx） | 预装会抢端口 | `纯净 / 有：____` |

## §C 一键采集（在服务器上跑，输出整段贴回）

```bash
echo "===== 忆述光华 · 服务器回报 ====="
echo "[A1] 公网IP:"; curl -s --max-time 5 ifconfig.me; echo
echo "[A3] SSH端口:"; grep -E '^Port ' /etc/ssh/sshd_config 2>/dev/null || echo 22
echo "[A4] 当前用户:"; whoami
echo "----- B 机器真值 -----"
echo "[B6] OS:"; grep -E '^(PRETTY_NAME|VERSION_ID)=' /etc/os-release
echo "[B7] 架构:"; uname -m
echo "[B2] CPU 核数:"; nproc
echo "[B2] 内存:"; free -g | awk 'NR==2{print $2" GB total, "$3" GB used"}'
echo "[B3] 磁盘:"; df -h / /data 2>/dev/null
echo "[B8] Docker:"; docker --version 2>/dev/null || echo "未安装"
echo "[B8] Compose:"; docker compose version 2>/dev/null || echo "未安装"
echo "[B8] Python:"; python3 --version 2>/dev/null || echo "未安装"
echo "[B9] 端口占用(5432/6379/6333/8010):"; ss -ltn 2>/dev/null | grep -E ':(5432|6379|6333|8010)' || echo "均未占用（干净）"
echo "[B5] 地域/可用区:"; curl -s --max-time 3 http://100.100.100.200/latest/meta-data/region-id 2>/dev/null; echo
echo "===== 采集结束 ====="
```

> 最后一条走云厂商元数据服务，直接报出实例所在地域（阿里云 / 腾讯云均支持该地址）。
