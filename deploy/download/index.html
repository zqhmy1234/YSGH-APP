三步装好

  1. 1

    允许安装未知来源

    下载完成后点击安装，系统若提示「禁止安装未知应用」，请在弹窗中点设置 → 打开允许来自此来源的应用，返回再点一次安装。

  2. 2

    华为 / 荣耀机型先关「纯净模式」

    EMUI / HarmonyOS 会拦截非应用市场来源的安装包。路径：设置 → 系统和更新 → 纯净模式 → 退出，然后再安装。装好可自行开启。

  3. 3

    首次打开授权麦克风与相册

    录音与照片整理都需要授权。麦克风权限只在第一次点录音时弹出，请选「允许」；若误点拒绝，请到 设置 → 应用 → 忆述光华 → 权限 手动开启。

常见问题

装不上 / 提示「安装失败」怎么办？

按顺序排查：① 是否已完成上面第 1 步（允许未知来源）；② 华为 / 荣耀是否退出了纯净模式；③ 下载是否中断（重新下载一次，注意文件大小与上方标注一致）；④ 手机上是否已装过同名的旧内测包——请先卸载旧版再装。

录音没有声音 / 录进去是空的？

绝大多数是麦克风权限没给。请到 设置 → 应用 → 忆述光华 → 权限 → 麦克风 打开后重试。

另外三种情况：① 开始录音后立刻结束（不足 0.5 秒）会被判定为「录音太短」并丢弃，请正常说一句话；② 录音时若来了电话，录音会被系统中断；③ 手机静音/勿扰模式不影响录音，但蓝牙耳机抢占麦克风会导致录不到，可先断开耳机再试。

打开后一直进不去 / 一直空白？

内测版连的是我们自己的测试服务器，需要在能正常上网的网络下使用。请依次检查：① 是否连了公司/校园内网或 VPN（可能拦住了我们的地址）；② 切换 Wi-Fi 与移动数据再试一次；③ 结束后重新打开 App。

内测版是按设备自动建档的：首次打开会为你单独建一个账号，不需要注册、也不需要输入邀请码。若换手机或重置系统，会变成一个新账号（旧数据不会丢，但需要在反馈群里联系我们处理）。
