## M-5 · 模型症状档案（skills/chat-quality-doctor/models/）

置信度四级：`observed`（可溯源实测，可引数字）> `community`（有来源的社区共识，只可定性转述）> `hypothesis`（推测，须明说）> `stale`（旧实验待复测，**禁引精确数字**）。

| 模型 | 实测状态 | 一句话要点 |
| --- | --- | --- |
| deepseek-chat | stale（27 组对照历史摘要） | 四律遵守度中等；语言指纹强的卡会「人设吃掉文风」（可接受）；社区口碑「中文天花板/性价比之王」，R 推理系不适合恋爱对话 |
| glm-4.6 | stale | 无约束时单轮极长；对字数约束**遵守度极高**（注入四律收益最大组）；上限别写 ≤60 字（电报腔反噬） |
| kimi-k2.6 | stale | 与 glm 同组（约束遵守度极高、收益大）；接口只接受 temperature=1.0 |
| qwen-plus | stale | **诗行式断行排版癖**是其 AI 味主源；四律必须搭配「正常段落排版」条款才有效 |
| claude 系 | 无实测·community | 社区公认活人感第一梯队（「会顶嘴有主体性」）；最贵、安全层最严；社区用法=日常便宜模型+关键剧情切 claude |
| gpt 系 | 无实测·community | 「引导型爱人」：稳定体贴会引导话题；情感浓度被官方压低 |
| gemini 系 | 无实测·community | 见档案 |
| grok 系 | 无实测·community | 见档案 |

诊断分流表（笼统抱怨 → 症状假设 → 首查）见 [`chat-quality-doctor/SKILL.md`](../skills/chat-quality-doctor/SKILL.md) §1。
