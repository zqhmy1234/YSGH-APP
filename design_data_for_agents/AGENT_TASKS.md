## 通用规范（所有 agent 必须遵守）

### 1. 技术栈要求

- **框架**：uni-app x（.uvue 文件）
- **模式**：Vapor 蒸汽模式（manifest.json 已开启 `vapor: true`）
- **API 风格**：组合式 API（`<script setup>`），**禁止使用选项式 API**
- **样式**：ucss（仅 flex 布局、仅 class 选择器、样式不继承、无伪元素、文字必须用 `<text>`）
- **图标渲染**：使用 hens-svg 插件（已导入 `uni_modules/hens-svg`）渲染 SVG 图标

### 2. 颜色体系（全局统一）

| 颜色名 | 色值 | 用途 |

| 背景色 | `#F8F7F4` | 页面背景 |

**跳转逻辑**：

- 我的 → `/pages/profile/profile`

### 4. 设计数据使用方法

每个页面的设计数据在对应文件夹的 `design_data.json` 中，包含：
- `all_elements`：所有 SVG 元素的完整列表（tag + attrib + text）
- `clipPaths`：裁剪路径定义
- `gradients`：渐变定义
- `filters`：滤镜定义
- `root_attrib`：SVG 根元素属性（width/height/viewBox）

**元素属性提取**：
- `rect`：x, y, width, height, rx, fill, opacity
- `circle`：cx, cy, r, fill
- `path`：d（路径数据）, fill, stroke, stroke-width
- `g`：transform, clip-path（分组，子元素在其内部）
- `text`：x, y, text（文本内容）, fill, font-size, font-family

**注意**：很多元素在 `<g>` 分组内，需要递归查找。坐标可能是相对于分组的，需要结合 transform 计算绝对位置。
