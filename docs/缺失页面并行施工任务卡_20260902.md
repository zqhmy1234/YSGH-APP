### G4. uvue 零先例禁令（写任何不确定语法前，必须先 Grep 项目先例）
本项目编译器对以下写法**零先例即不认**，全部禁止凭空使用：
1. 禁 `!.` 非空断言（模板和 script 都不行）。
2. 禁 type 字面量构造 `Xxx(field: ...)` → 对象一律 `class + constructor + new`（先例：`MessageItem` / `DayGroup`）。
3. 禁函数默认参数 `= []`。
4. 禁 CSS 复合选择器 / 后代选择器 / 伪类；CSS 动画（keyframes）不确定能落地时，写静态降级版并登记台账（先例：VoiceWave 呼吸动画降级）。
5. `as number` 改字面量；`onLoad` 签名对齐先例（Grep `pages/detail/detail.uvue`）。
6. 渐变只写**双停靠**（三停靠零先例，先例：theme-detail）。
7. `v-for` 必带 `:key`；ref 数组更新用**下标重建重赋值**，不用 splice（splice 零先例）。
8. 弹层组件用 **`v-if` 卸载复位**，不用 defineExpose（零先例）；scrim + sheet 结构对齐先例 `components/EchoSheet/EchoSheet.uvue`。
9. 只用项目里出现过的 uni API；要用的 API 先 Grep `client/utils/` 和 `client/pages/` 确认先例，没有就降级 + 登记台账。
10. 组件目录放 `client/components/<名>/<名>.uvue`（easycom 自动注册，无需注册组件）；`lang="uts"` 与 vue API 按先例对齐。
