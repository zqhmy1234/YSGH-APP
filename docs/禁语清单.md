# 禁语清单（单一来源 · B7-02）

本清单是共情检查的唯一人工维护来源。`agent/src/harness/empathy.py` 与
`backend/app/domain/guard/empathy.py` 的常量必须与本表逐条一致；角色卡
`taboo` 只能是本表的子集，不得新增措辞。

维护规则：改本表 → 同步两处常量 → 跑 `agent/tests/harness/test_empathy.py`
与 `backend/tests/guard/test_empathy.py`。禁止把本表复制进任何 prompt。

## 禁语

| 禁语 | 原因 |
|---|---|
| 别想太多 | 否定用户的感受 |
| 你为什么这样 | 质问、把责任推回用户 |
| 怀念吗 | 替用户预设情绪 |
| 你应该 | 说教、替用户做决定 |
| 这有什么好难过 | 贬低用户的感受 |
| 你就是难过 | 定义用户的情绪 |
| 你其实很在意 | 替用户解释内心 |
| 你一定是 | 把猜测说成事实 |

## 句式模式

`你就是` / `你其实` / `你一定是` / `你不该` / `没什么大不了` / `想开点`

## 诊断词

`抑郁症` / `焦虑症` / `确诊` / `精神病` / `人格障碍`
