## 三、数据链断言测试设计（每链三层断言）

**架构拍板项（见 grill Q4）**：主体形态=后端 pytest 集成测试（每链一个 test 函数，跑在
test_agent 全量门禁内），真机 E2E 冒烟（scripts/realdevice 基建）只覆盖 L3/L5/L10 的端侧段。

**三层断言模板**（每条链统一）：
1. **HTTP 层**：状态码 + 响应 schema 关键字段非空
2. **DB 层**：落库终态（status/关联行/字段非空）
3. **副作用层**：COS 对象存在性 / echo_history 名额 / qdrant 向量 / 本地缓存

| 链 | 断言用例（核心断言语句） |
|---|---|
| L1 | 登录 200 → users 行存在 → 无 token 访问受保护端点=401；过期 token 刷新后重放 200 |
| L2 | seed N 事件 → timeline 200 返回 N 条 → events 全 confirmed → event_items 关联数与 contents 对齐 |
| L3 | 上传 wav → upload/init 200（id 合法字符）→ form 200 → contents 行 status 经管线终态 confirmed（限时断言）→ text 非空 → cos_key 非空 → **COS 对象 HEAD 200** → event_items≥1 |
| L4 | 上传 jpg → 同上三层 + 缩略图票据/旁路 downloadFile 200 |
| L5 | 对 confirmed voice：GET /media/audio 200 + Content-Type 音频 + 字节数>0；对 processing voice：**明确态断言（409/占位，随 grill Q1 拍板）**；对不存在 id：404 |
| L6 | seed 已索引内容 → search 200 → 命中该 id → 与 timeline 同源一致性（同一 content 双链均可达） |
| L7 | seed 去年今日 → echo/today 返回 1 条 → 再调仍同一条（幂等）→ respond 后当日再调=空（名额）→ dismiss 不占名额（UNIQUE 部分索引语义）→ **echo 消息 payload 含 content_id（R9-1 修复后）→ 按 payload 回放 200** |
| L8 | messages 200 → unread 计数=DB read_at IS NULL 数 → markMessageRead 后 read_at 非空 → markAllRead 后 unread=0 |
| L9 | favorite 后 favorites 页可见 → unfavorite 后消失 → 回收站软删 → 恢复后回原位 |
| L10 | /media/{key} 200 字节>0；过期票据 403；token 缺失 401 |
| L11 | contents?content_id 200 且 content_type 与 DB 一致；**voice 内容返回含音频可播标识（随 R9-5 拍板）**；不存在 id 显式错误非静默 |
| L12 | reconcile 触发 → 增量拉回与本地对账 diff=0 |
