## 九、数据资产概述（docs/ 下 396 个 JSON 文件）

develop 分支的 `docs/` 目录下除 7 个 md 外，还有 **396 个 JSON 数据文件**，分为四类：

| 类别 | 数量 | 说明 |
|---|---|---|

| `docs/_l1_refine/*.json` | 193 个 | L1 层精修后数据，与 `_l1_in` 一一对应 |

这些是**用户画像/BFI2（Big Five Inventory-2）大五人格画像维度的分层标注数据资产**。文件名维度可辨识出：`bfi2_facets`（15 个，对应 BFI2 的人格面）、`bfi2_domains`（5 个，对应大五五域）、`big5_self`（3 个）、`pref_peeve`、`emotional_state`、`emotional_curve`、`dominant_trait`、`habit_goal/budget/daily/doomscrolling`、`energy_level`、`event_importance`、`geo_life`、`comm_reading/storytelling/precision/optimism/politeness/verbosity`、`domain_characteristics` 等。

`_l0`/`_l1` 是画像标注管线的层级（L0 粗标 → L1 精修），`_in` 是输入、`_refine` 是精修产出。它们服务于产品"qwen-flash 画像标注"链路的语料/真值沉淀，而非后端接口或前端代码。
