### 2. 跨模态检索 A+B+C（新功能）

| 方案 | 内容 | 关键文件 |
|---|---|---|
| **A** 照片 → 全模态 | 以图搜图新增 caption 文本路，与 `image_vec` 路 **RRF 跨量纲融合**（不取最大分——余弦 0.5~0.7 与 RRF 0.016 差 30 倍，取最大会让文本路永远输且静默退化） | `rag/image.py`、`rag/recall.py` |
| **B** 音频 → 全模态 | 新增 `POST /api/v1/search/audio`（multipart → ASR → 复用 `rag.search`）；客户端 `searchByAudio` + 「语音搜」入口 | `rag/audio.py`(新)、`api/search.py`、`TabSearch.uvue` |
| **C** 文字 → 全模态 | `_route_query` 三态（image/mixed/text）+ 显式 `intent` 覆盖；含图词但有实词走 mixed 双路，`intent=image` 显式仍只回照片（回归保护） | `rag/intent.py`、`rag/__init__.py` |

**端到端实证**：

| 查询模态 | 结果 |
|---|---|
| 文字「拍的语音」 | `intent=mixed` → 语音 1 + 照片 4 |
| 音频（真实 wav） | 200，ASR 转写「Yeah。」→ 语音 1 + 照片 2 |
| 照片（真实 jpg） | 200 → **照片 8 + 语音 1 + 文字 5**（hits=14） |

**已知限制**：照片→文字/语音靠 caption 语义近似命中，非像素级（写入侧 text/voice 无 `image_vec`，不改 Qdrant schema 无解）；图搜多一次 sparse 编码 + 一次 Qdrant 查询，P95 待复测；`TabSearch.uvue` 908 行（structure WARN 非阻断）。

## 三、本轮走查的两个技术结论（值得 reviewer 知道）

1. **所有"按钮点不动"最终都是坐标打偏**（偏 340~1100px），不是产品不可点。可靠定位法：**颜色扫描找实心按钮**（`r>150 && 60<g<130 && b<100`）+ 灰度找文本行；`uiautomator dump` 对 uni-app-x 只暴露 input，拿不到自绘按钮。
2. **模拟器麦克风一直可用**：此前"录音不可验"的真因是**启动参数带了 `-no-audio`**（AVD 本身 `hw.audioInput=yes`）。去掉后 2.6/2.7 顺利验通。
