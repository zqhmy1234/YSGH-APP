## A 段：你手动做（PowerShell，逐条粘贴）

### 地雷 1：BgBackground.kt 头注释"嵌套毒"
**是什么**：`client\uni_modules\yishu-background-tasks\utssdk\app-android\BgBackground.kt` 第 8 行注释里写了 `libs/*.jar`——那个 `/*` 在 Kotlin 里会**开启一个嵌套块注释**（Kotlin 注释支持嵌套），导致头注释到第 24 行关不掉 → 编译器报 `Unclosed comment at :1`，.kt 永远编不过。
**怎么改**：把那句注释里的 `libs/*.jar` 换成 `libs 目录下全部 jar`（纯注释改动，不碰逻辑）。

```powershell
$p='D:\GuangH-App\client\uni_modules\yishu-background-tasks\utssdk\app-android\BgBackground.kt'
$s=[IO.File]::ReadAllText($p)
$s=$s.Replace('直接把 libs/*.jar 加入','直接把 libs 目录下全部 jar 加入')
[IO.File]::WriteAllText($p,$s,(New-Object System.Text.UTF8Encoding($false)))
# 核验（应输出 0）：
([regex]::Matches([IO.File]::ReadAllText($p),'libs/\*\.jar')).Count
```

（也可以直接用编辑器打开该文件第 8 行手改，效果一样。）

### 地雷 2：listenablefuture-1.0.jar 是假的（404 网页存成了 jar）
**是什么**：`client\uni_modules\yishu-background-tasks\utssdk\app-android\libs\listenablefuture-1.0.jar` 只有 689 字节，内容是一个 `<html><title>404` 报错网页——当年 AgentK 下载 Maven 依赖把报错页存成了文件。Kotlin 编译器读它直接炸 classpath（`Failed requirement`）。.kt 全文不引用 ListenableFuture，**纯死件，删了没有任何影响**。
**怎么改**：资源管理器删掉它（进回收站），或：

```powershell
Add-Type -AssemblyName Microsoft.VisualBasic
[Microsoft.VisualBasic.FileIO.FileSystem]::DeleteFile('D:\GuangH-App\client\uni_modules\yishu-background-tasks\utssdk\app-android\libs\listenablefuture-1.0.jar','OnlyErrorDialogs','SendToRecycleBin')
```
