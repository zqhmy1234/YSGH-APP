## G1（认证安全）

### 任务
1. **refresh single-flight（R6#6）**：`client/utils/auth.ts` 共享 in-flight refresh——并发 401 只触发一次 refresh，其余 await 同一 Promise，消除并发双轮换竞态。
2. **logout/revoke 端点（R6#7）**：新增服务端 logout/revoke（devices 表吊销 refresh token，AUTH-006 语义）；客户端 logout 调用并清本地凭据。
3. **refresh_token HMAC 哈希列（R6#8，TD-P3 已加列则补强）**：TD-P3 已加 `refresh_token_hash/refresh_rotated_at` 列，核实 `services/auth/auth.py` 的 `_hash_refresh_token/_rotate_refresh_token` 已接线、哈希强度够（HMAC-SHA256 + 密钥隔离），不足则补。
4. **SMS 验证码加盐（R6#9）**：验证码存储哈希加盐（对齐 P0-1 已验证码 SHA-256 的既有实现，补盐与原子消费）。
5. **通用限流中间件（R6#2/#3）**：`backend/app/core/` 新增限流中间件（Redis 滑动窗口/令牌桶，按 client_ip 或 user 维度），**先覆盖 auth/ASR/搜索三域**；`core/middleware.py` 现仅 RequestIDMiddleware，新增不得破坏 request_id 链路。

### 文件域（只许改这些）
`backend/app/api/auth.py`、`backend/app/services/auth/`（auth.py 哈希/轮换/吊销）、`client/utils/auth.ts`、`backend/app/core/`（新增限流中间件，不动 errors/queue 既有契约）、`backend/app/db/models.py`（仅 G1 所需列）+ `backend/migrations/versions/`（新迁移）

### 验收
- 受影响域精准测试全绿（test_auth_db/test_security_p3/test_techdebt_p0/test_phone_login 等 auth 相关）
- 每 commit 快速门禁 EXIT=0；契约快照 diff：openapi auth 路径**新增允许**（logout/revoke）、旧路径零消失；errors.py 无错误码消失
