### 1.3 模拟器与部署（关键，踩过很多坑）

```powershell
# 启动模拟器（AVD yishu35，端口 5554）
$s="$env:LOCALAPPDATA\Android\Sdk"; $env:ANDROID_AVD_HOME="D:\Android\avd"
Start-Process "$s\emulator\emulator.exe" -ArgumentList "-avd","yishu35","-no-snapshot","-no-audio","-gpu","swiftshader_indirect","-no-boot-anim" -WindowStyle Minimized

# ⚠️ 必须建立反向代理：模拟器到宿主 LAN(192.168.31.165) 的 NAT 已断，直连必超时
adb -s emulator-5554 reverse tcp:8010 tcp:8010

# 部署（HBuilderX 单实例单队列，无 --device；每次 100–125s）
D:\HBuilderX\cli.exe launch app-android --project client --compile false
```

**运维红线（每条都实际踩过）**
1. `adb emu kill` 会挂死不返回 ⇒ 用 `Get-Process qemu-system-x86_64 | Stop-Process -Force`
2. `pm clear io.dcloud.uniappx` 会**连 HBuilderX 推的资源包一起清掉**，之后必须重新 `cli launch`，否则基座报 “application resources are not detected”
3. 基座卡「手机无响应」⇒ `am force-stop` + `pm clear` + 重跑 `cli launch`
4. 第二台模拟器**无法独立运行 App**（手工复制基座 APK + `apps` 资源后仍被拒）⇒ 多模拟器并行部署本工具链下不可行
5. **首次点击普遍被吞**：tab / 按钮常需连点两次
6. 底部 tab 坐标（1080×2400）：时间轴 165 / AI 334 / 搜索 715 / **我的 919**；中央 `+` (540,2263)
7. 截图缩放：491×1050 → 真机 ×2.2(x) ×2.285(y)
8. 模拟器**无摄像头、麦克风无输入**（`pcm_readi failed`）⇒ 拍照与中文语音转写类验收无法在此环境完成

### 2.3 性能现状（本机，数字不可信，仅供对比）

| 条件 | 消费吞吐 | 说明 |
|---|---|---|
| 1 worker（进程内带模型） | 0.22 条/秒 | 每进程 ~1.2GB |
| **4 worker（进程内带模型）** | **0.11 条/秒** ❌ | `os error 1455` 页面文件不足 |
| 1 worker（走共享 embedding 服务） | 0.17–0.21 条/秒 | **worker 内存 86MB**（vs 1.9GB） |

结论：瓶颈是「每进程各加载一份大模型」，不是队列解耦。共享服务已落地，**扩 worker 的前提已具备，但必须在专机量**。

### 2.4 未修的缺陷（按优先级）

1. **`process_content` 无 job 超时** —— 单个 job 卡死会永久堵死单线程 worker（Windows 无法强杀）。
2. **按钮命中区比绘制区上移约 33px** —— 暂停态「结束并转写」视觉中心 1887 点不动、1854 能点。已试过抬高容器内边距、给按钮显式 `height:64rpx`，**均未对齐**；不是调 CSS 能猜出来的，需要看 uvue frame 与绘制差异。
   （踩坑记录：`var(--d-lattice-p156, 360rpx)` 里令牌存在=300rpx，fallback 永不生效，白改一次。）
3. **同日多卡未合并**（同一天 3 条内容 = 3 张卡），upsert 合并未做；标题带摘要只是止痛。
4. **首次点击被吞**（影响面最大）。
5. **消息列表顶部约 240px 空白**。
6. **相关性阈值偏松**：搜不存在的词也返回 10 条。注意 `retrieval_min_dense_score` 默认 0 是**有实测依据**的（正负样本稠密分几乎重叠），不能硬设阈值。
7. ~~`sparse_score` 恒为 0~~ **【已排除，2026-11-01】**：真实链路（带 user_id 过滤）稀疏分正常输出；直查无过滤时的"恒 0"是 RRF 融合窗口表象。真正修的是**相关性阈值偏松**：`retrieval_min_dense_score=0.55` + `retrieval_min_sparse_score=0.01`（sparse 救援）已上线 `.env`，搜不存在的词返回 0 条（台账 §4.9）。
8. 账号与安全页写「注销后数据永久删除」，但后端无注销端点（文案回归）。
9. 存量卡旧标题需回填；**修复前入库的乱码语音内容**（`0c56f2f4` 等）需数据修复或忽略（测试数据）。
