### 迁移方案（关键：**不需要重新出包**）

现有 APK 指向 `coleslaw-absence-harvest.ngrok-free.dev` 这个 **ngrok 静态域名**。
Ngrok 静态域名可以**改指到任意一台机器** —— 只要在服务器上跑 ngrok agent 用同一个 authtoken：

```
本机（现在）:  ngrok → 10.20.28.21?? 不对，是 → 127.0.0.1:8010（本机后端）
迁移后:        服务器上跑 ngrok → 127.0.0.1:8010（服务器后端）
两者用同一个 authtoken + 同一个静态域名 ⇒ 客户端地址丝毫不用改
```

⇒ **已出的 APK 可直接复用**，不需要重出包。唯一要求：同一时刻只能有一处占用该静态域名。

### 但要如实说清三个代价

1. **GPU 用不上（对本项目）**：忆述光华的大模型走 DashScope API，本地只跑 BGE-M3（CPU）。
   BGE-M3 在 GPU 上确实能快很多（这正是 B-11 的瓶颈），**但需要先把 GPU 修好**。
2. **服务器是别人（超声项目）在用的**：`student03` 只是普通用户，不碰他人目录；
   我们的 PG/Redis/Qdrant 必须用独立端口与独立数据目录。
3. **内网 IP `10.20.28.21` 只能校内访问**，公网 IP `202.120.234.69` 从家里测不通
   ⇒ 隧道是唯一对外路径，**隧道一断，所有已装 APK 立即不可用**（与本机时代同样的单点）。
