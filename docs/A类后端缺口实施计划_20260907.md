> **原则**：

## BA1 字段补齐批（A6/A8/A9余量/A10）

**核心动作：一个 migration 一次收四个字段，落库点+出参+前端接线三点同步。**

| 项 | DB 变更 | 落库点 | 出参 | 前端接线点（已留槽） |
|---|---|---|---|---|
| A6 duration | Content 加 `duration`（int 秒，nullable） | 语音转写 done 时写入（转写响应自带时长或探针读取 wav 头） | VoiceInfo / timeline / detail | 语音卡空闲态 duration 槽位（非活动态显真实时长） |
| A8 remark | Content 加 `remark`（text，nullable） | save 系接口收 remark 参数入库 | detail 出参 | F1d 备注卡 remark-input 真提交 |
| A9 余量 | Content 加 `size_bytes`（bigint，nullable） | 上传落盘时量文件体积写入 | 新 stats/usage 出参（PE stats 端点扩展） | storage 用量卡从「条目数聚合」改真实字节 |
| A10 content_id | messages 加 `content_id`（uuid，nullable） | 复盘/语音完成消息生成时带 content_id（回响消息已有，对齐口径） | MessageOut 加 content_id | messages.uvue openMessage 补一行 navigateTo（骨架已留） |

- **顺手修**：R9-A2（voice taken_at=NULL）随本 migration 一并回填存量（`UPDATE ... SET taken_at=created_at WHERE content_type='voice' AND taken_at IS NULL`）+ register 时落非空值——回响/去年今日按 taken_at 查询才能捞到语音。
- **验收**：迁移测试绿；四条总账行验收标准逐条过；openapi 实证。

## BA2 CRUD 批（A2/A3/A5）

### A2 收藏 favorite
- 前置核对：28 表 schema 是否预留 favorites 表（决策台账口径），无则新建（user_id+content_id 唯一约束 + created_at）。
- 端点草案：`POST /api/v1/contents/{id}/favorite`、`DELETE /api/v1/contents/{id}/favorite`、`GET /api/v1/favorites`（分页）；content 出参带 `favorited` 布尔防 N+1（批量查询）。
- 接线：detail 收藏钮 + favorites 页真数据（USE_MOCK_FAVORITES 关）。

### A3 删除（软删 30 天 + 回收站）
- 复用 US-49 同步层已有 `deleted_at` 软删语义，**不新造删除模型**；补 App 端删除链路设计文档补缺（F7 组拍板要求，先补文档再动代码）。
- 端点草案：`DELETE /api/v1/contents/{id}`（软删）、`GET /api/v1/trash`、`POST /api/v1/trash/{id}/restore`、`DELETE /api/v1/trash/{id}`（硬删）、30 天清理挂既有后台任务体系。
- 接线：trash.uvue onRestore/onClearAll/goTrash 三处真数据（USE_MOCK_TRASH 关）；detail 删除钮接真（B12 该 toast 随之接真）。

### A5 时间胶囊（已排期 W2-3，留总账跟踪至落地）
- 端点草案：`POST /api/v1/capsules`（封存）、`GET /api/v1/capsules`（查询，分未到期/已到期）、到期开启走既有端点 + **到期推送**（2026-09-02 峰宝拍板全量含推送；推送复用 messages 体系生成「胶囊已到期」消息，A10 content_id 顺带覆盖）。
- 接线：CapsuleSheet 真封存（USE_MOCK_CAPSULE 关）；detail 胶囊按钮去假 toast。

- **验收**：三条总账行验收标准；B8 三个 mock 开关（favorites/trash/CapsuleSheet）关闭；pytest 全绿。

## BA3 AI 链批（A1/A7）

### A1 LLM 动态打标（chips 真值来源）
- 拍板口径（F1 组）：标签=AI 动态生成不限枚举；SetFit 5 类（情绪/灵感/混合/引用/待办）保留作分类域，**不作 chips 真值**。
- 方案：内容 done 后追加打标任务（low 队列，与聚合同管线），qwen-flash 产出 chips JSON 存新列 `tags_json`；detail 出参下发。
- 注意：存量内容一次性回填任务（复用 RQ 批量模式）；打标失败显式落 status 不静默（项目军规）。

### A7 照片 AI 描述 + 分类入库
- 描述：照片入库管线接 qwen3-vl 生成描述存列（A1 同批 migration 或独立列）；detail 照片卡 F1g AI 描述行接真。
- 分类：`/api/v1/classify` 与 `/api/v1/corrections` **端点已存活零接线**（09-04 侦察实锤）——前端 submitCorrection 接线即通，手选分类真入库。
- **验收**：detail chips 为 AI 生成；照片标注页显 AI 描述行；手选分类入库可查。
