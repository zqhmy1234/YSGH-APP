2. **N+1 上提循环外**：`_l3_confirmed_exists` 的用户标题集合查询上提到 `_write_upper_candidates` 循环外（每用户 1 次）；L3 linked/owned 检查合并为 `IN (cluster)` 单条查询；`sync_client_events` 幂等查改 `client_event_id IN (...)` 批量、photo_ids 归属按批合并。

4. **3 个缺失索引**（schema.sql + 新迁移，本地库需同步执行验证）：`deleted_logs(cleanup_status, deleted_at)`、`offline_queue(user_id, id)`、`messages(user_id, id)`。
5. **reconcile O(N×M)→O(N)**：client_items 先建 `set(entity_id)`；`_cloud_entities` 投影列只取所需。
6. **profile_annotator**：`get_or_create_profile` 提循环外；`_trim_history` 合并单条 SQL；`profile_l2_evidence` 补 `(user_id, dimension)` 索引。
7. **echo**：敏感话题按需查询/一次缓存；LLM 检测仅首候选。
8. **correction.mark_global_candidates**：改单条 SQL 聚合 + 批量 UPDATE（不载全表）。
9. **wechat `_corp_access_token` 进程内缓存**（带过期，失效重取）。
10. **storage cos/minio 进程级单例**（与 fake 同模式）。

**明确不做（登记遗留）**：upload.py 流式合并（COS copy_object/append 依赖后端能力，P2 批次或另排）；pipeline.py patch_extra 样板收敛（P2B）。
