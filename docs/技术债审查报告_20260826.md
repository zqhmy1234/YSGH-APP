## 二、高危（P0，必须优先修）

### 安全类（S7 + S4 交叉）
1. **生产短信验证码 mock 直返 → 任意手机号账户接管**（auth.py:116 send_sms 无 app_env 门控；mock_external_ai 默认 True）。一行门控可堵：production 下 mock 一律 501（对照 wechat_login 已有先例）。
2. **COS STS 整桶通配 policy**（storage.py get_sts_credentials：`{bucket}/*` 整桶写；root ARN 派生；/upload/sts 无环境门控）→ 任一登录用户可跨用户覆盖对象/存储耗尽。需路径级 policy（photos|voice|thumbnails/{user_id}/*）+ 非 root 凭证 + 端点门控。
3. **上传无文件内容嗅探 + 请求路径同步 PIL 解码**（contents.py:103 仅扩展名/content_type 判断；thumbnails.py 无 MAX_IMAGE_PIXELS）→ 内容投毒 + 解压炸弹 DoS。补魔数校验（ASR 链路已有先例 `_matches_magic`）+ MAX_IMAGE_PIXELS + 缩略图移 worker。

### 正确性类（S3）
4. **process_content 非 voice 失败永久卡 processing**（pipeline.py:552-568 仅 voice 回写 failed；text/photo 静默失败无状态、无重试、无告警）→ 补 failed 回写 + 超龄 processing 扫描重试。
5. **complete 后建内容非幂等**（upload.py register_photo_content original 模式每次新建；commit 后 enqueue 抛异常→客户端重试→重复内容）→ photo 分支对齐 voice 的"同用户+同 cos_key 幂等"。
6. **外部存储裸异常 + 孤儿对象**（contents.py:171/wechat:180/upload.py put_object 无包装；写对象后 commit 失败无补偿删除；cleanup 不覆盖）→ StorageError(code, retryable) + best-effort delete + 孤儿对象扫描。
7. **错误码同码多义**（CONTENT_003=敏感/游标；CONTENT_007=413/404）→ 建立错误码登记表 + 单测校验唯一语义。

### 性能类（S6）
8. **aggregate_user 每次内容处理全量重扫 400 条 + L2/L3 从零重算 + 逐候选 LLM**（pipeline.py:487 → events.py:51-56/283-292）→ 批量导入 O(N²)，队列塌陷。增量游标化 + 候选去重 + LLM 批量裁决。
9. **事件聚合/端侧同步 N+1**（_l3_confirmed_exists 逐候选重复查用户标题；sync_client_events 每事件 2 查询）→ 上提循环外 + IN 批量。

### 测试类（S5）
10. **测试写生产 Qdrant collection**（vector_store.py:21 默认 `yishu_contents`；门禁靠顺序 hack + 自动重试掩盖）→ 测试专用 collection（前缀 test_）+ 每跑清理。
11. **RAG 门禁盲区**（pytest.ini `-m "not rag"` → 19 个检索用例 CI 不跑，rerank 仅 28% 覆盖）→ CI 增加 rag 分组执行或并入 full-gate。
12. **test_event_ops 无过滤全表删除**（Event/EventItem/EventEditLog 全删，与同库数据冲突即静默清库）→ 按 user 过滤。
