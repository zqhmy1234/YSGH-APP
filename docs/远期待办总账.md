## 一、照片处理专项（优先，与产品照片输入主线对齐）

### PHOTO-1 ✅ 百度 OCR 文字转写接入照片管线（已实现 2026-09-26；真机端到端验证待 Key）

- **目标**：照片中的菜单/收据/路牌/屏幕笔记等文字被识别入库，作为无 GPS 照片聚合的内容主信号。
- **现状**：✅ 已实现。凭证已配置（`config.baidu_api_key/baidu_secret_key`）；聚合链路 `RawPhoto.ocr_text` → `_ocr_summary()`（取前 3 条各截 60 字）原本就预留，无需改动。
- **本次实施（2026-09-26，3 处改动）**：
  1. 新建 `backend/app/services/external/baidu_ocr.py`：百度 `accurate_basic` 高精度版（CHN_ENG；access_token 进程内缓存过期前 600s 刷新；最长边 2000px 压缩防 216205；网络抖动/5xx 走统一 `with_retry` 3 次指数退避；鉴权缺失抛 `OcrNotConfiguredError`、业务错误显式抛错不静默；图片字节无法解析改抛普通 RuntimeError 防被误判网络错误重试）。
  2. `backend/app/services/pipeline_photo.py::_process_photo` 追加 OCR 步骤（caption 之后、CI 打标之前）：识别文字写 `content.extra.ocr_text`，并拼入 `content.text`（`OCR\ncaption` 并存）→ 主提交后 `_index_after_commit` 自动索引进 Qdrant（全文检索命中）。失败语义同 caption：显式 log 后仅跳过 OCR 增强。
  3. `backend/tests/test_pipeline.py` 新增 2 用例：`test_photo_ocr_writes_ocr_text_and_merges`（成功：extra.ocr_text 写入 + text 拼入）、`test_photo_ocr_failure_silent`（失败：照片仍 done、text 保持 caption、不写残缺值）。
- **剩余项（待真实环境）**：① 真机/沙箱端到端验证需真实 `BAIDU_API_KEY/BAIDU_SECRET_KEY`（当前本地无 Key）；② 场景后处理 `extra.ocr_scene`（菜单/收据/路牌/屏幕笔记四类 LLM 归类）为可选增强，未实现；③ 集成测试需 PG/Redis/Qdrant 环境运行（本地 pytest 环境不可用，已用 py_compile 语法验证）。
- **验收**：上传含文字照片后 `extra.ocr_text` 非空、全文检索命中；无 GPS 照片事件标题/描述引用 OCR 摘要。

### PHOTO-3 ⏳ 悬浮窗快捷截图录入（悬浮球 + 截图 → 自动走照片管线）

- **目标**：任意 App 场景下悬浮球一键截图，截图自动入库并复用照片管线（OCR/打标/聚合）。
- **现状**：无任何系统级悬浮窗/截图代码（client 仅 CSS 悬浮投影；`yishu-photo-watch` 是相册监听插件非悬浮窗）。
- **实施步骤**：
  1. 新建 `client/uni_modules/yishu-float-window` UTS 插件（app-android）：
     - `WindowManager.addView()` 加悬浮球，`TYPE_APPLICATION_OVERLAY` + `FLAG_NOT_FOCUSABLE`；支持拖动/贴边吸附。
     - `SYSTEM_ALERT_WINDOW` 权限：`Settings.canDrawOverlays()` 检测 → 跳授权页 → 返回回检（复用 photo-watch 权限申请模式）。
  2. 截图能力：`MediaProjectionManager` 首次授权 → `MediaProjection` → `ImageReader` 抓帧为 Bitmap → 存临时 JPG。
  3. 截图后自动入库：位图 → 复用分片上传链路（`upload/init→chunk→complete`）→ 落 `contents`（content_type=photo）→ 异步 `_process_photo`（自动 OCR + 标签 + 聚合）。
  4. 悬浮球展开快捷面板（拍照/说一段/写几句），唤起既有 `RecordSheet`（`directPick` 直达表单）。
  5. 前台服务保活：挂前台通知，复用 `yishu-background-tasks` dataSync 保活模式（短命化、超时自停）。
- **验收标准**：开启权限后悬浮球跨应用可用；截图入库后 App 内可见整理结果（标签/事件）；权限拒绝有诚实提示。
