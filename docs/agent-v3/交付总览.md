# agentv3 交付总览（Agent 系统）

## 一句话

`agent/src/agentv3/` 是一套**可独立运行、可被证伪**的陪伴 Agent 系统：五角色分工、十二端口隔离、六域业务能力、九段上下文、批次化记忆写入，全部由 `agentv3.judge` 自动裁决。

## 模块 → 测试 → 输入/有效性 → 输出/有效性

> 完整 33 行（含每条断言）见机器生成的 [`模块测试说明.md`](模块测试说明.md)。下表是分组速览。

| 模块组 | 做了什么测试 | 输入 | 输入是否有效 | 输出 | 输出是否有效 |
|---|---|---|---|---|---|
| `contracts` / `ports` | pydantic 约束 + 导入图边界 | JSON 载荷、端口参数 | 未知字段/空文本/超 6 alternates/日期倒序 → 拒 | 强类型对象 / PortError 三态 | 枚举封闭；失败必抛错，不伪造空结果 |
| `plan` / `registry` / `frame` | 表驱动意图、预算、裁剪顺序 | TurnContext | 纯数据、无时钟无 IO | TurnPlan / AgentSpec / Frame | llm_down 时 0 次 LLM；越权写抛错；证据先裁、边界与修正不裁 |
| `muse` / `librarian` | 限步、只读工具、RRF、两列、降级 | 查询、框架、工具表 | alternates 与预算受限；空查询回 clarify | 回复 + Trace / SearchResult | 引用可回切原文；降级不冒充搜到；`empty` 前必查原文 |
