> 口径：本仓库交付的是**Agent 系统**（`agent/src/agentv3/`）及其证伪体系。
> 端侧 UI、账号体系、原生插件、云上服务（Qdrant/COS/企业微信）不在本包内；它们在契约层留口，未接的如实标 🟡/❌，不以「全绿」冒充。
