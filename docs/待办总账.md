1. **新任务 / 状态变更只写本表**；5 份旧账本只存历史，不再更新（各有顶部告示）。
2. **销项三步**：改本表状态 → 在「附录 · 已闭环」追加一行证据 → 若属决策类，回 `docs/决策台账.md` 对应条回填。

4. **每条必须有「下一步」**，否则它不是待办、是抱怨——请归到 F 区并写清前置。
5. 本表条目数变化时同步更新顶部「分区索引」表。
6. **与 `docs/决策台账.md` 的关系（两边不打架的前提）**：台账 §5/§7 **仍在正常维护**——它是决策与缺陷的
   **判定记录**（为什么这么定、依据是什么、谁拍的板）；本总账是**任务视图**（谁要做什么、卡在哪、下一步）。

   台账判定发生变化时**必须同步本表对应行的状态**；反之本表销项时也要回台账回填。
   **不得**以「已并入总账」为由停止维护台账，也不得把台账的判定理由抄进本表（那样必然二次漂移）。
