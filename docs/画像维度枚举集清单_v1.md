# 画像维度枚举集清单（忆述光华 · 第一版）

> **用途**：① 画像系统（B1）落地核心资产——L0/L1 维度定义与枚举值 ② F 批画像标注真值的对照清单（产品部标注时照此填 `dimension`/`enum_value`）③ 技术侧实现参考
> **原料**：MatrAIx 1290 维 schema（`E:\Workbuddy\2026-08-12-14-43-00\matraix_schema\dimensions.json`）+ 忆述光华 B1-B5 深度设计 + 4 视角群策（产品旅程/LLM 消费/数据原料/防错兜底）+ grill 五分支收敛（2026-08-25，峰宝×北嘎霖）
> **规模**：L0 核心 50-80 维 + L1 领域 150-200 维（从可用 ~1100 维中选取，非全收）
> **配套**：画像三层披露/证据锚点/置信度机制见 B1；敏感红线走 B5-b 护栏

## 〇、设计总则（grill 五分支收敛结论）

| # | 原则 | 内容 |
|---|---|---|
| 1 | **素材层优先** | LLM 要"可引用的原话、可排序的主题、可避开的雷、可匹配的情绪、可去重的历史"——**标签进思考、证据进话术**；解读层（人格标签）只做约束不做素材 |
| 2 | **超细维度全量建** | Big5 50+Character 34 全建，但三层披露（L1 常驻索引 / L2 场景扩展 / L3 全量）+ 证据锚点转译 |
| 3 | **证据锚点+新鲜度** | 每维度带证据原话+时间戳；消费时按新旧打折（半年前的证据=曾经如此，近期=现在如此） |
| 4 | **置信度门槛** | 普通维度 ≥0.7 更新；超细性格维度 ≥0.8（需多证据累积，宁缺勿错） |
| 5 | **能抽靠抽、抽不动靠访谈** | 情绪/主题/习惯/关系靠碎片抽取；价值观/性格/部分敏感靠冷启动访谈（B1-7 三问）兜底 |
| 6 | **中国化优先** | 中国式关系/人生事件/节假日/平台自建；MatrAIx 通用层（性格/沟通/健康/习惯）复用；美国议题/开发者/学术熟悉度排除 |
| 7 | **敏感两层分治** | 画像只管用户个人敏感（话题×处置 5 级）；红线级（涉政/违法/未成年/医疗诊断）走 B5-b 护栏硬规则，不进画像枚举 |
| 8 | **开放枚举** | 枚举值=种子值（非封闭集合）；LLM 标注匹配不上→同义归一→直接新增（带证据+时间戳）；防碎片/生命周期/晋升/审计治理见 B1 §2.3 修订 |

## 三、枚举值设计规范（分支⑤收敛）

| 规则 | 内容 |
|---|---|
| 常规维度 | **4-6 个枚举值**（对齐 MatrAIx 中位 5）——够用且好标 |
| 自然集合维度 | 关系称谓/节假日/人生事件等**闭合自然集合**：放开到 **10-20 值**（中国亲戚称谓/节日就那么多，不靠拍脑袋） |
| 两级结构 | **关系类/兴趣类用两级**（粗值 L1 索引省 token + 细值 L2 详情）；其余扁平 |
| phrase 模板 | **保留 + 中文化**（如"今年 {value} 岁"）；**证据原话优先**，无证据才用 phrase 兜底 |
| 时间戳 | 每维度必带 updated_at；证据带时间戳，消费按新旧打折 |
| 扩展机制 | **开放枚举**：枚举值 = **种子值**（人设计起点，非封闭集合）；LLM 标注时匹配不上 → 先**同义归一**（查维度别名表）→ 确无等价值才**直接新增**（带证据+时间戳即时入集，不等人）；防碎片/生命周期/晋升/审计治理见 B1 §2.3 修订 |

## 四、敏感维度设计（分支④收敛 · 安全红线）

### 4.1 两层分治

| 层 | 管什么 | 机制 | 例子 |
|---|---|---|---|
| **画像敏感**（user_profile） | 用户**个人**敏感 | 话题×处置 5 级 + 证据锚点 | "前任"=forbid，"家人住院"=review |
| **红线硬规则**（护栏） | 所有人通用的法律/安全红线 | B5-b 预置词表 + 百炼检测 + **fail-safe 默认拒发** | 涉政/违法/未成年人/自残/医疗诊断 |

### 4.2 画像敏感维度结构（sensitive_topic）

```
话题（12 固定 + 用户自定义扩展）
× 处置级别（5 级）
× 来源（user 显式标记 / auto 自动识别 / echo 回响联动）
× 证据锚点（原始表达 + 时间戳）——"别再提前任了"
× 生命周期（画像级永不过期 / 事件级提及≥3 次降级）
```

### 4.3 处置 5 级

| 级别 | 行为 | 触发 |
|---|---|---|
| `allow` 放行 | 正常处理 | 非敏感/已释怀 |
| `mention` 可提 | 可自然提及 | 普通敏感（轻微尴尬） |
| `caution` 慎提 | 当前情绪低落时不提，否则可提 | 情绪相关敏感 |
| `review` 复核 | 先问"想聊聊吗"再决定 | 拿不准的高敏感（家人住院） |
| `forbid` 绝口不提 | 永不主动提 | 用户显式标记/创伤 |

### 4.4 12 固定话题（+ 默认处置）

| 话题 | 默认处置 | 说明 |
|---|---|---|
| 前任/恋情分手 | forbid 或 review | 回响/追问最大雷区 |
| 家人健康/住院 | review | 先问再提 |
| 亲丧/离世 | review | 边界难例 |
| 家庭矛盾/吵架 | caution | |
| 财务困境/欠债 | forbid | |
| 心理健康（抑郁/自残） | forbid + 护栏联动 | 自残=红线，必拦 |
| 身材/外貌 | forbid（禁评） | |
| 宗教/信仰 | caution | 不表态 |
| 政治立场 | caution | 不表态 |
| 工作/学业受挫 | caution | |
| 被霸凌/创伤经历 | forbid | |
| 隐私信息（收入/住址） | forbid（不引用） | |

### 4.5 深水区敏感（平常议题之外）

| 档 | 内容 | 出错后果 |
|---|---|---|
| 身份级 | 性取向/性别认同（未出柜）、成瘾、被侵犯、创伤 PTSD | 信任崩塌，用户卸载 |
| 关系级深层 | 出轨/背叛/家庭秘密/私生子 | 隐私彻底失守 |
| 红线级 | 涉政/违法/未成年/医疗诊断 | 法律/安全事故（走护栏） |

## 五、F 批标注对照（画像标注真值怎么填）

产品部标注 F 批时，`expected_updates` 里 `dimension` 从本清单取，`enum_value` 从该维度的枚举值取：

```json
{
  "profile_case_id": "pf-0001",
  "input_text": "项目延期了，感觉被掏空",
  "expected_updates": [
    { "dimension": "emotional_state", "enum_value": "焦虑", "confidence": 0.82, "should_update": true },
    { "dimension": "stress_level", "enum_value": "高", "confidence": 0.75, "should_update": true }
  ],
  "user_id_hashed": "sha256:...",
  "collected_at": "2026-09-01T10:00:00+08:00"
}
```

**新增 sensitive_topic 维度标注**（敏感识别也有真值尺子）：

```json
{
  "profile_case_id": "pf-0002",
```
