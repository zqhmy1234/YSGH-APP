## 执行顺序与依赖

1. **P0 先行**（安全/正确性，1 个批次）：完成后即可安全推进一切重构。
2. **P1 并行**（配置契约 + 性能测试，2-3 个 Agent）：依赖 P0 的错误码登记表（P0-7）先落地。
3. **P2 并行**（死代码 + 重复收敛，2 个 Agent）：依赖 P1-B 的 conftest（先做 conftest 再做 fixture 收敛）。
4. **P3 并入**：安全二线随 P0/P1 批次附带，不单独开批。
5. 每批：快速门禁（commit）+ 全量门禁（review_agent --full）+ 集成 Agent merge + harness 更新 + 教训登记。
