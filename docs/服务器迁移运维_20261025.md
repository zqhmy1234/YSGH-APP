## 依赖服务（Docker Compose，`~/yishu/docker-compose.yml`）

```bash
cd ~/yishu && docker compose up -d      # 起 PG + Redis + Qdrant
docker compose ps                        # 状态
```

⚠️ **坑**：`/mnt/ee16` 是特殊挂载，**容器内无法 chown bind mount 目录**
（`chown: Operation not permitted`）⇒ 必须用 **docker named volume**，不能用 `./pgdata:/var/lib/postgresql/data`。

## 启动应用服务

```bash
bash /tmp/ss.sh          # 幂等：停旧 → 起 backend/worker/agent → 等就绪 → 打日志尾
```

或手动：
```bash
cd ~/yishu/src/backend && setsid nohup ~/yishu/venv/bin/python -m uvicorn app.main:app \
  --host 127.0.0.1 --port 8010 --log-level warning > ~/yishu/logs/backend.log 2>&1 &

cd ~/yishu/src/backend && setsid nohup ~/yishu/venv/bin/python -m app.workers.worker \
  > ~/yishu/logs/worker.log 2>&1 &

cd ~/yishu/src/agent/src && setsid nohup ~/yishu/venv/bin/python -m uvicorn main:app \
  --host 127.0.0.1 --port 8300 --log-level info > ~/yishu/logs/agent.log 2>&1 &
```

## 隧道（客户端唯一入口）

```bash
~/bin/ngrok http 8010 --domain=coleslaw-absence-harvest.ngrok-free.dev \
  --log=$HOME/yishu/logs/ngrok.log --log-format=logfmt &
```

- authtoken 已写入 `~/bin/ngrok config`
- 查状态：`curl -s 127.0.0.1:4040/api/tunnels`
- ⚠️ **同一静态域名全账号只能一处占用** ⇒ 起服务器隧道前必须先停本机 ngrok

## 迁移踩过的 5 个坑（都实测过）

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| 1 | `/mnt/ee16` 不能 chown | PG/Redis 容器无限重启 `chown: Operation not permitted` | 改 **docker named volume** |
| 2 | 驱动包 vs 内核模块版本不匹配 | `nvidia-smi` 报 `Failed to initialize NVML` | **CUDA 其实完全正常**（`torch.cuda.is_available()=True`，matmul 实测通过）。只是 smi/NVML 坏了，**不用 sudo、不用重启** |
| 3 | `app_env=production` 触发安全守卫 | 启动即 `RuntimeError: 生产环境必须配置 JWT_SECRET` | 服务器 .env 补 `JWT_SECRET`（新生成）。⚠️ 画像两把加密 key **必须沿用本机值** |
| 4 | `pg_dump --inserts` 不带列名 | 两库列顺序不同 ⇒ `contents`/`events`/`devices`/`messages` **整表导入 0 行**，且只报一行错 | 改 **`--column-inserts`** |
| 5 | DashScope 工作空间子域 DNS 不通 | agent `APIConnectionError`；`ws-xxx.beijing.maas.aliyuncs.com` **解析失败** | 显式设 `AGENT_LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1`（公共端点实测 200） |

另：`git clone` 从服务器拉 GitHub **反复断流**（`GnuTLS recv error` / `port 443 timeout`）
⇒ 改 **本机 `git archive` 打包 → scp**。
