## 二、范围 In/Out

**In**：
- 文字入口：POST /api/v1/contents（text）+ 分类异步（job 轮询）+ 分类标签可改（三层裁决）
- 语音入口：POST /api/v1/asr/transcribe（wav ≤8MB）+ 转写可编辑 + 情绪标签展示（关怀文案库产品部待提供）
- 搜索入口：POST /api/v1/search + /search/image（以图搜图）+ 溯源展示 + 降级态处理（依赖后端降级契约）
- 回响：GET /echo/today + POST /echo/{id}/dismiss（首页"去年今日"卡片）
- 冷启动访谈：GET /interview/questions → POST /answers → 画像（三层披露 + 可跳过）
- 消息中心：复盘 22:00 push + 回响 in-app 统一列表
- 底部 Tab 四宫格导航（时间轴/记录/搜索/我的）

**Out（后续）**：
- Windows F9 → 第四波
- WiFi 原图/蜂窝缩略图 → 继续推迟
- L2/L3 手动确认 UI → 后续
- 微信"收"客户端触点 → M3 服务端主导，客户端后续

## 四、技术要点

- 文字/语音/搜索后端全部就绪（contents / asr / search + image），第三波纯客户端接线
- 分类异步：P2-01 已改 classify/arbitrate 异步 + job 轮询，客户端按 job 轮询进度
