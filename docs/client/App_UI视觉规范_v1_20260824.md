# 忆述光华 · App UI 视觉规范 v1（grill-me 收口版 · 2026-08-24）

> 由 UI 设计讨论线产出（峰宝逐项拍板）。先行于第一波 F8 开发，后续所有界面（第一/二/三波）以此为准。
> 铁律来源：风格签名五要素 / 反 AI 默认四反 / 克制即美（用户级记忆）。

---

## 一、气质锚点

**方向 A：相纸·胶片记忆感**（峰宝拍板 ✅）
- 记忆=一张张相纸：暖白相纸底 + 时光痕做旧 + 物件隐喻
- 反 AI 默认：不几何（线条不规则）/ 不冷调（暖白底）/ 不完美（撕边+底部阴影）/ 不填满（≥30% 留白）

## 二、品牌 3 色（峰宝拍板 ✅，3 色限定铁律）

| 角色 | 色值 | 用途 |
|---|---|---|
| **相纸白** | `#F6F1E7` | 全局基底（暖白底，非纯白） |
| **墨褐** | `#3A2E25` | 文字/线条/图标主色（非纯黑，旧墨感） |
| **锈红** | `#B05A3A` | 强调/CTA/回响卡片/关键数字（唯一情绪出口） |

- **语义色例外**（非品牌色，使用量 <5%）：错误红/成功绿/警示黄
- 冷色系（蓝/紫/青）一律禁用；三色外任何装饰色 = 违规

## 三、字体

- **标题**：衬线体（宋体系，旧报纸/信笺的回忆感）——Android 用系统 serif / Noto Serif CJK
- **正文**：无衬线（现代可读）——系统默认字体

## 四、隐喻物件（峰宝拍板 ✅，物件=符号非装饰）

| 位置 | 物件 | 隐喻 |
|---|---|---|
| Tab：时间轴 | 相册页 | 翻看记忆 |
| Tab：记录 | 铅笔+纸 | 书写记忆 |
| Tab：搜索 | 旧式放大镜 | 寻找记忆 |
| Tab：我的 | **印章**（峰宝把邮戳改为印章） | 归属/印记 |
| 空状态：照片 | 空白相纸 | 还没有照片 |
| 空状态：搜索 | 空胶卷盒 | 没找到 |
| 空状态：消息 | 未拆信封 | 没有消息 |
| 回响卡片 | 旧照片角贴 + 泛黄一档 | 去年今日=被贴起的旧照片 |
| 启动页 | 照片显影中（模糊→清晰） | 记忆逐渐显现 |

## 五、时光痕载体（峰宝拍板 ✅，核心边界）

> **做旧只落在"记忆载体"类元素，导航/按钮保持干净**（防老气 + 保可点性的双保险）

| 元素 | 载体 |
|---|---|
| L1/L2 卡片 | 右下角轻微撕边 + 底部投影（不描边） |
| 全局背景 | 微噪点纹理（低对比，隐约可见） |
| 回响卡片 | 泛黄一档 + 角贴（全 App 唯一明显做旧区） |
| 导航栏/按钮 | 干净（不做旧） |

## 六、资源格式策略（峰宝拍板 ✅，SVG 适用性边界）

| 资源类型 | 格式 | 说明 |
|---|---|---|
| Tab/通用图标 | **iconfont 字体图标** | 选中态变色友好，uvue 支持自定义字体 |
| 噪点/颗粒纹理 | CSS 渐变 或 平铺 PNG | SVG feTurbulence 滤镜 Android 不可控 |
| 泛黄渐变 | CSS 渐变 | SVG 复杂渐变易转位图 |
| 显影动画 | CSS 动画 / PNG 帧序列 | **官方不支持 SVG 动画** |
| 撕边遮罩 | PNG 遮罩 或 border-radius 切角 | SVG clip-path 在 uvue 支持有限 |
| 简单几何图形/印章/简洁插画 | **SVG**（保留矢量） | mode 用 scaleToFill/aspectFit，不 flatten、不用裁剪类 mode |
| 写实插画 | PNG（@2x/@3x） | 矢量不适合复杂光影 |

**硬规则**：所有资源放 `/static` 目录（其他目录不打进包）；文件名大小写敏感。

## 七、组件基线（开发时按此执行）

- 卡片：圆角小（相纸感，不追求大圆角），底部投影，撕边一处
- 按钮：主 CTA 用锈红（唯一大面色块），次操作用墨褐描边，禁用其他色
- 留白：≥30% 全局留白（列表/页面/弹窗）
- 空状态：三件套插画 + 一句话文案 + 一个动作按钮
- 回响卡片：泛黄 + 角贴 + 划掉交互（dismiss）

## 八、验收口径（前端自审铁律）

- 页面截图自审：从用户视角检查配色越界/留白不足/做旧过度/可点性
- 75 分交付线：不达标不交付
