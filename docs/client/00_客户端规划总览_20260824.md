## 🗂 决策速查（全部已拍板）

### 波次范围
| 波次 | 窗口 | 范围 |
|---|---|---|
| 第一波 | W3-4 | F1 链路（相册→上传→云侧全链聚合→回读）+ F8 时间轴（L1+L2 只读）；必须在线；端侧不落 XView |
| 第二波 | W5-10 | 离线+同步：端侧 ST-DBSCAN（L0/L1 真值）+ XView 5 表 + B4 同步协议 + STS/分片 + 手动操作 UI |
| 第三波 | W11-14 | 多入口（文字/语音/搜索）+ 玩法层（回响/访谈/消息中心） |
| 第四波 | W15+ | Windows F9（Electron+Python sidecar，单列） |

### 关键架构决策
- 端侧 L0/L1 真值 + 云侧 L2/L3（B3-6 定稿；第一波临时云侧全链，第二波回归）
- 照片上传：第一波后端中转 multipart（新端点 `/api/v1/contents/upload`），第二波 STS 直传 + 分片
- 端侧事件上云：`POST /api/v1/events/sync`（client_event_id 幂等）
- 同步：字段级 LWW + 云端胜兜底 + op_id 幂等队列 + 三路触发 + 软删 30 天
- 认证：dev mock wechat（code=dev-client）→ 正式登录等凭证
- 推送：应用内拉取（打开/切前台刷新消息中心），厂商推送后置
- 环境：dev baseURL=本机后端（模拟器 10.0.2.2 / 真机局域网 IP），minio 存储

### UI 视觉（v1）
- 3 色：相纸白 `#F6F1E7` / 墨褐 `#3A2E25` / 锈红 `#B05A3A`；衬线标题+无衬线正文
- 隐喻：Tab=相册页/铅笔纸/放大镜/印章；空状态=相纸/胶卷盒/信封；回响=角贴+泛黄
- 时光痕边界：做旧只落记忆载体，导航按钮干净
- 资源：图标 iconfont、纹理/遮罩 PNG/CSS、简单图形 SVG（不支持 SVG 动画）
