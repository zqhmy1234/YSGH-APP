## 三、P1 重点（按域摘录，完整清单见各 rN 报告）

### 后端数据/事务（R2，9 条 P1）
1. process_content 单事务横跨分钟级外部调用（COS/ASR/LLM/Qdrant），Qdrant 副作用无补偿 → 孤儿向量。
2. 嵌套 commit 破坏原子性：notify.create_message/guard.reflow_violation_words/amap geo_cache 在管线事务内 commit，emotion.py 头注与实现不符。
3. 每条内容触发一次 aggregate_user 全量预载（批量导入 O(N×400)）。
4. 敏感标记每内容逐类全量扫用户内容（JSONB 无 GIN 索引）。
5. ORM models.py 与 schema.sql/基线迁移索引漂移（autogenerate 会生成 DROP INDEX）。
6. sync push_ops 批内同键重复 op → 永久 IntegrityError 500。
7. refresh token 轮换无锁竞态（重放窗口）。
8. phone 验证码 used_at 置位竞态（同码双登录）。
9. get_or_create_profile check-then-insert 竞态（并发首标 500）。

### 客户端（R3，6 条 P1）
1. time.ts dayKey/friendlyDay/shortDate 三份活拷贝、time.ts 同函数零消费（P2B 收敛残留）。
2. ISO→ms 解析双实现且行为分歧（Z 后缀被当本地时间，时差 8h bug 隐患）。
3. DEVICE_ID 双源定义（auth.ts vs sync_client.ts，历史已出事故）。
4. 401 刷新重放策略分裂：event_sync 静默丢弃整批 L1 事件。
5. sync_client.syncHttp 整段复制 api.ts 网络层（两套演进）。
6. 双离线队列并存（yishu_sync_op_queue vs yishu_op_log，同六字段不同实现）。

### API 契约（R4，4 条 P1）
1. 22 处 raise 裸字符串错误码未引用 ERR_* 常量（规则被静默绕过）。
2. 无效 UUID → psycopg2 DataError → 500（8+ 端点无防护）。
3. 服务层 ValueError/KeyError 二元异常不足以表达 404/409/413/422（events/upload 两域语义错位）。
4. POST /contents text/article 无幂等键，双击/重试即重复入库。

### 异步（R5，3 条 P1）
1. 事件聚合在 process_content 内同步执行：批量上传 O(N²) 且并发 worker 下重复建 L2/L3。
2. process_content 无 job 级去重：9 个入队点可双入队。
3. process_content 尾段"先提交后入队"：commit 与 enqueue 之间崩溃丢情绪任务。

### 安全（R6，6 条 P1）
1. 手机验证码登录无尝试限流（OTP 爆破面）。
2. 客户端 refresh 无 single-flight → 轮换竞态偶发掉登录。
3. 客户端 token 明文存储 + 硬编码 device_id（设备绑定形同虚设）。
4. classify/corrections 异步任务归属未强制（CLASSIFY_003/CORR_004 已定义未使用）。
5. create_content cos_key/thumbnail_key 客户端可控无归属校验（CONTENT_009 未启用）。
6. 无 logout/revoke 端点（AUTH-006 未落地）。

### CI/工程化（R7，4 条 P1）
1. client/（uni-app x）零 CI 覆盖，"全仓门禁"名不副实（_skip_path 整目录排除）。
2. 分类/重排真实模型路径 CI 从未验证（门禁静默降级）。
3. 覆盖率门禁不一致：CI(50) < 本地默认(60)，rag 步骤不计覆盖。
4. backend/.env.example 与 setup_pg.sql/CI 凭据不对齐（超级用户 vs 最小权限）。

### 测试（R8，4 条 P1）
1. test_auth_db.py 固定登录身份 + LIKE 清理 → 跨运行污染（实测 flaky，4 连败）。
