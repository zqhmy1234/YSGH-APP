## 三、密钥与恢复（在服务器进程内/隔离环境）

1. **原 key 仍可用**：用保管包恢复出的两把 key，在服务器进程内做一次合成值 AES-GCM 加密 + HMAC 校验；与运行时 key 比对（仅内存，不落盘/不回显）。
2. **密文可恢复**：对含合成密文的隔离库执行 `pg_dump -Fc` → 恢复到新的隔离库 → 用原 key 解密，校验明文与 hash 一致；错误 key 必须被拒绝。
3. **备份可恢复**：取观察期内最新一份自然备份，恢复到本机 PG17 隔离库；核对 33 张 public 表、迁移号 `c1d2e3f4a5b6`、列结构指纹、逐表行数与生产一致。
4. **API/回响/导出**：在隔离副本上跑
   `pytest backend/tests/test_profile_sensitive_crypto.py backend/tests/test_profile_sensitive_migration.py backend/tests/test_echo.py backend/tests/test_export.py -q`
