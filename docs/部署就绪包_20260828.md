## 1. `.env.production` 模板（占位符）

> 用法：复制为 `backend/.env.production`（或按部署方式注入环境变量），`APP_ENV=production` 启动。
> 占位符规则：`<必填>` = 未填会导致生产启动拒绝（见 config 生产兜底）；`<占位>` = 接线后替换；`<接 key 后>` = 当前未接入，待 key 到货启用。

```dotenv
# ============ 忆述光华 backend · 生产配置（占位符模板） ============
# 复制为 backend/.env.production；真实值仅经 Infisical 获取，禁止提交明文。

# --- 环境 ---
APP_ENV=production
DEBUG=false
# CORS 白名单（逗号分隔；生产默认空=同源；有前端域名则填 https://app.example.com）
CORS_ORIGINS=

# --- 服务 ---
HOST=0.0.0.0
PORT=8000
# 对外可达基址（生成链接/回调用）
BASE_URL=https://api.example.com

# --- 数据库 / Redis / Qdrant（部署环境连接串）---
DATABASE_URL=postgresql+psycopg://<用户>:<密码>@<PG_HOST>:5432/yishu
REDIS_URL=redis://<REDIS_HOST>:6379/0
QDRANT_URL=http://<QDRANT_HOST>:6333

# --- 密钥（生产安全兜底强制项，默认值会拒绝启动）---
JWT_SECRET=<必填：≥32 字节 CSPRNG 随机串，如 openssl rand -hex 32>
REFRESH_TOKEN_HMAC_KEY=<必填：独立于 JWT 的 HMAC-SHA256 密钥，≥32 字节 CSPRNG>
JWT_ACCESS_TTL_MINUTES=120
JWT_REFRESH_TTL_DAYS=30
JWT_ALGORITHM=HS256

# --- Mock（fail-closed：生产强制 false；漏配将拒绝/强制关闭）---
MOCK_EXTERNAL_AI=false

# --- 对象存储：生产 = COS（STS 直传）---
STORAGE_BACKEND=cos
COS_BUCKET=<必填：腾讯云 COS 桶名>
COS_REGION=<必填：桶地域，如 ap-guangzhou>
TENCENT_SECRET_ID=<必填：腾讯云子账号 SecretId>
TENCENT_SECRET_KEY=<必填：腾讯云子账号 SecretKey>
TENCENT_APPID=<占位：腾讯云账号 AppId（公开参数）>
TENCENT_STS_ROLE_ARN=<占位：客户端直传 STS 角色；未配自动降级后端中转>

# --- 阿里云百炼（qwen-flash / 护栏 / 画像标注）---
DASHSCOPE_API_KEY=<必填：百炼 API Key（len≥64）>
DASHSCOPE_WORKSPACE_ID=<必填：sk-ws- 工作空间 ID（工作空间级 key 必须带）>
DASHSCOPE_REGION=cn-beijing
DASHSCOPE_BASE_URL=

# --- 本地声学情绪（SenseVoice，生产必须预置目录避免首请求联网下载）---
ASR_LOCAL_EMOTION_MODE=auto
SENSEVOICE_MODEL_DIR=<占位：scripts/prepare_sensevoice.py 预置后的绝对路径>

# --- 高德逆地理（照片位置 → 地名）---
AMAP_API_KEY=<必填：高德 Web 服务 key>

# --- 百度 OCR（含文字图片识别）---
BAIDU_API_KEY=<必填：百度智能云 OCR key>
BAIDU_SECRET_KEY=<必填：百度智能云 OCR secret>

# --- 内容安全审核（上架前切 aliyun；当前默认 tencent_ci）---
CONTENT_SAFETY_PROVIDER=aliyun        # 上架前；未开通阿里内容安全前可回退 tencent_ci
ALIYUN_ACCESS_KEY_ID=<接 key 后：阿里云「内容安全」AccessKey（⚠️非百炼 key）>
ALIYUN_ACCESS_KEY_SECRET=<接 key 后：同上 SecretKey>
ALIYUN_CONTENT_SAFETY_REGION=cn-beijing

# --- 可观测（Sentry 崩溃上报，双通道云版）---
SENTRY_DSN=<必填：Sentry DSN>

# --- 限流（部署在可信反向代理后开启 trust_proxy）---
RATE_LIMIT_TRUST_PROXY=true    # 反代后为 true；直连请保持 false
RATE_LIMIT_WHITELIST=

# --- 短信验证码（阿里云短信；后端待接线，接 key 后启用）---
# ⚠️ 当前 config.py 未接线 SMS_*，属预留占位——接 key 后需后端补配置项再启用
SMS_ACCESS_KEY_ID=<接 key 后>
SMS_ACCESS_KEY_SECRET=<接 key 后>
SMS_SIGN_NAME=<接 key 后：短信签名>
SMS_TEMPLATE_CODE=<接 key 后：验证码模板>

# --- uni-push（客户端离线/关怀推送；uni-app 端配置，接 key 后启用）---
# ⚠️ uni-push 在 client 端（manifest/云服务）配置，非 backend .env；以下为占位备忘
UNI_PUSH_APPID=<接 key 后>
UNI_PUSH_APPKEY=<接 key 后>
UNI_PUSH_MASTER_SECRET=<接 key 后>

# --- 企业微信「微信客服」（F6；MVP 微信入口，认证通过后启用）---
WECHAT_CORP_ID=<接 key 后>
WECHAT_TOKEN=<接 key 后>
WECHAT_ENCODING_AES_KEY=<接 key 后>

# --- 微信开放平台登录（MVP 可保留 mock→生产 501；上架前接真实 AppID/Secret）---
WECHAT_APPID=<接 key 后>
WECHAT_SECRET=<接 key 后>

# --- 检索 RAG（保持 .env.example 基线；GPU 部署按门禁开启重排）---
RERANKER_MODEL=bge-reranker-v2-m3
RERANK_MIN_SCORE=0.0
RERANK_ENABLED=false            # 仅 GPU 且 P95<3s 探针通过才置 true
RERANK_AUTO_ENABLE=false
RERANK_MAX_CANDIDATES=20
RERANK_LLM_ENABLED=true
```

> **占位符 ↔ 变量名对照**：以上变量名与 `backend/app/core/config.py` 字段逐一对齐（含别名读取：`TENCENT_SECRET_ID↔TENCENT_CI_SECRET_ID`、`COS_BUCKET↔TENCENT_COS_BUCKET`、`AMAP_API_KEY↔AMAP_WEB_API_KEY`、`ALIYUN_ACCESS_KEY_ID↔ALIYUN_AK_ID` 等），可直接对照 `.env.example` 校验。

## 3. 密钥获取与生成指引（不含真实值）

| 项 | 来源 | 说明 |
|---|---|---|
| JWT_SECRET / REFRESH_TOKEN_HMAC_KEY | 本地生成 | `openssl rand -hex 32`（CSPRNG ≥256bit）；HMAC 与 JWT 独立 |
| COS / 腾讯云 | Infisical | 子账号最小权限；STS 角色按需 |
| 百炼 / 高德 / 百度 / Sentry / 阿里内容安全 | Infisical | 各平台按 `忆述光华_外部API申请操作手册.md` 申请 |
| 短信 / uni-push / 企微 | Infisical（到货后） | 团队/key 阻塞项，接 key 即启用 |

> 完整申请与 Infisical 用法见：`忆述光华_交付文档/外部API与密钥/`（申请手册 / 账号管理方案 / Infisical 操作手册）与 `skills/infisical-secrets/SKILL.md`。
