## 提交纪律（所有 F Agent）

1. `git commit -- <paths>` 路径限定，禁止 `git add -A`；提交前 `git diff --cached --name-only` 核对。
2. 每 commit 过快速门禁（pre-commit hook 自动）。
3. 不 push；报告文件留集成 Agent 统一提交。
4. 行为等价迁移：先拆包纯搬移 → 精准测试绿 → 再动跨包依赖。
5. 完成后显式呼叫集成 Agent（merge + 精准门禁 + CI 验证 + 契约快照 diff）。
