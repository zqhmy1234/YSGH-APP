## 8. 工具化产物：`scripts/audit_harness.py`（三轴审计，已落成并实测）

**为什么要门禁化**：§2.2/§3 的漂移之所以能长期潜伏，是因为**没有任何门禁覆盖它们**——openapi 再生是人工步骤（无 CI 断言）、`USE_MOCK_*` 无清点手段、注释里的死路径无人扫。审计若只出一份报告，三个月后同样会漂回去；故按 `scripts/check_schema_drift.py` 的体例落成可执行门禁。

**用法**
```bash
python scripts/audit_harness.py openapi|client|models|all [--json out.json]
# 退出码：0 = 无 CRITICAL；1 = 有 CRITICAL（契约双向漂移 / 代码内死路由 / 模型 0 引用）；2 = 环境错误
```

**首次实测结论（2026-09-23）**

| 轴 | 结论 | 判据 |
|---|---|---|
| 契约双向对拍 | ✅ **64/64 完全对齐**，无幽灵路径、无方法差异 | 本地 `app.openapi()` vs `docs/openapi.json`；**顺带纠正**：本报告初版曾据 `OpenAPI契约.md` 称"积压 17 条"，实为 09-21 重导后已消除 |
| 客户端漂移 | ✅ 无死路由、无 `.ts` 残留；⚠️ **B8 清单过时**（8 个 mock 开关实际只剩 1 个） | 已更新 `远期待办总账.md` 头部注 |
| 模型使用率 | ✅ **0 引用模型 0 个**；16 个低引用（信息性，供人工判） | 25 个模型类 / 11 个文件 |

**工具自身的两个假阳性（已修并留痕——本报告要求自己同等标准）**

| 缺陷 | 现象 | 根因 | 修法 |
|---|---|---|---|
| 路径比对未归一化 | 误报 **44 条"代码内死路由"CRITICAL** | `pages.json` 的 `path` 无前导斜杠（`pages/shell/shell`），代码引用带斜杠 → 全量误判 | 两侧 `lstrip("/")` 归一化后比较 |
| 裸词匹配开关 | 把**注释里提到的开关名**算成真开关（9 处含 5 处假阳性） | 用 `\bUSE_MOCK_\w+\b` 裸词匹配，未限定声明形态 | 只认 `const/let X = true|false` 声明（9→1） |
| GBK 控制台崩溃 | 遇 `✓` 抛 `UnicodeEncodeError` 直接中断 | 未处理 Windows 默认 GBK 编码 | stdout/stderr 统一 UTF-8 + 不可编码字符降级 |

> **教训**：审计工具的**假阳性比缺陷本身更危险**——它会直接把错误结论写进台账。故新增工具**必须先用已知样本自校验**（本次若不自校验，就会在台账里留下"44 条死路由"的假记录）。

### 8.1 轴 4 追加：导出-引用可达性（**闭本报告 §6.3 自列的未覆盖项**）

§6.3 曾声明"未逐文件审计 `client/utils/*.uts` 的零调用导出，其它零调用能力函数可能存在"。该缺口现已**工具化关闭**（`audit_harness.py exports`，纯静态、零外部依赖）。

**首查结果（296 个导出符号）**：

| 分类 | 数量 | 处置 | 代表 |
|---|---|---|---|
| **零调用的能力导出** | **9** | CRITICAL（写了没接线） | `searchByImage`（图搜）· `enqueueDeleteOp`/`enqueueFieldOp` · `submitArbitrate`/`pollArbitrate`（纠错裁决）· `addBreadcrumb`/`captureMessage`（Sentry 埋点）· `pendingPhotoCount` · `MAX_DIRECT_UPLOAD_BYTES` |

| 低引用（≤2 处）导出 | 89 | INFO | `AuthError` · `DayGroupResult` … |

**分类为什么必要**：若不分开，18 个契约常量会把 9 个真信号淹没——门禁一旦变吵就会被绕过。**能力函数零调用 = "写了没接线"**（图搜那类缺口的通用形态），故列为 CRITICAL；契约常量零调用多数只是预留。

**首查新增的独立线索**：`submitArbitrate`/`pollArbitrate` 零调用说明**纠错裁决链路在客户端压根没接线**——这为观察项 **O-2（纠错裁决恒"混合"）与缺陷 D-22** 提供了一条此前不存在角度的证据（此前诊断聚焦"回声覆盖+层①锁死"，未涉及"链路未接"）。
