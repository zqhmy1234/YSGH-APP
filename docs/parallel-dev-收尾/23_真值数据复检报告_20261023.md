## 4. D 批：素材已找到，标注表仍不可转换

### 实际照片

| 来源 | 数量 | 命名 |
|---|---:|---|
| `D:\audios and photos\d(images)` | 13 | `d001.jpg` 至 `d014.jpg`，没有 `d004.jpg` |

`d(images) (2).zip` 是 `d(images)` 的压缩副本，不重复计数。

### 标注表缺口

- D1 有 63 条有效明细，但只有 5 条填写事件编号，覆盖 3 个事件：E01、E02、E05。
- D2 有 5 条有效明细，其中 3 条填写主题编号，覆盖 2 个主题：T01、T02。
- 表中出现的照片名是 `a-0001.jpg`、`IMG_0101_masked.jpg` 等示例或另一套命名，无法与现有 44 张文件建立可信的一一映射。
- 缺少规格要求的 `set_id`、`window`、`time_span`、`photo_refs`、`annotator_count`、`consensus`、`expected_l1`、`expected_l2` 和 `expected_l3`。
- 没有证据表明这 44 张照片已经完成人脸、证件和车牌打码。
- 没有 2 至 3 位标注者的独立结果，技术侧不能编造 `consensus` 或 `annotator_count`。

### 最低限度需要补充

数据提供者应提供一份可按 `photo_id` 唯一匹配的映射表，至少包含：

| 字段 | 要求 |
|---|---|
| `photo_id` | 必须是现有 44 个真实文件名之一 |
| `set_id` | 同一志愿者的照片集合编号 |
| `timestamp` | 从 EXIF 读取的原始时间 |
| `location` | 脱敏到城市或区县，不保留门牌 |
| `window` | `short` 或 `long` |
| `final_event_id` 或 `theme_event_id` | 按事件分组后的编号 |
| `event_label` 或 `theme_label` | 事件名称 |
| `annotator_count` | 实际独立标注人数 |
| `consensus` | 实际一致的标注者比例，如 `2/3` |
