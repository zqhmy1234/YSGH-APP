## 5. 根因族（跨模块共同模式，本方案的"深度"所在）

| # | 根因族 | 含义 | 证据密度 |
|---|---|---|---|
| **RC-A** | **"定义即交付"错觉** | UI 壳 / API 函数 / 契约常量写齐就当作功能完成；**缺"点击 → 落库"端到端断言** | 15+ 处 |
| **RC-B** | **静默降级被当正常** | `if not token: return` / 恒 `hold` / 坐标 `null` / fail-open —— 全部**无日志、无告警、无 UI 提示** | 6+ 处 |
| **RC-C** | **本地状态写了但无人消费（假开关）** | 写 storage / 写 ref，全仓零读取 ⇒ 用户以为生效 | 3 处（含**合规风险**的隐私开关） |
| **RC-D** | **链路中段被恒假条件短路** | 一处 `return 'hold'` 让**整条蜂窝上传路径**永久停摆 | 1 处、影响面极大 |
| **RC-E** | **重构只搬代码、没搬"接线与范式"** | TabSearch 有正确性能写法未铺开；批量替换误伤字段（`manualLabel`）；并发写丢声明 | 3 类 |
| **RC-F** | **平台边界未纳入设计** | v-show 不停响应式 / `@keyframes` 不支持 / 无 worker / 裸 `let` 非响应式 / 模板函数插值响应性不确定 | 5 条（uni-app x 专属） |
| **RC-G** | **搬迁残留** | 死 helper / 死 CSS / 空函数 / 无监听 emit | 5 处 |

**防复发措施（批次 7）**：把 RC-A/C/D 变成**静态门禁规则**——
① client storage 键"写入无消费者"检查；② 契约常量零调用检查（轴 4 已有能力，扩展到 client 常量）；③ 模板函数调用插值扫描（性能反模式，白名单已有正确写法的文件）；④ `if not token: return` 型静默降级扫描（服务间令牌域）。
