# 周报（开发 C 线）

> 起始：2026-10-16（用户要求「从今天开始，以周为周期做每周工作汇报文档」）

## 约定

- **周期**：**由用户按需触发**；报告的**截止时间 = 用户要求产出的那一刻**（不固定星期、不建固定时刻的自动任务）；
- **覆盖窗口**：上一份周报的截止点 → 本次产出时刻；**首期**从约定建立日（2026-10-16）起算；
- **命名**：`YYYY-Www_开发C周报.md`（ISO 周号，按**截止日期**归周；例如截止 2026-10-16 → `2026-W42`）；
- **模板**：`_模板.md`（新一周复制它，别改历史报告）；
- **数据来源**（写报告时按顺序取）：
  1. `git log --since=<上一份截止> --author="ZLY20"`（本窗口内自己推的提交）
  2. `docs/parallel-dev-收尾/20_R2复验与C线测试执行台账.md`（复验/关单矩阵、待办 TODO）
  3. `research/truth-data/_reports/blockers_{c,d,e}.md`（真值数据检测结论）
  4. 上一份周报的「下周计划」（逐条对照，没做完的要写明原因）
- **用途**：① 向项目开发者/负责人汇报进度 ② 与数据提供者（产品部）交涉的依据——所以**每条都要有证据**（提交号 / 文件路径 / 实测数字），不要只写"已推进"。

## 触发方式

不建自动任务。用户在需要时提出「出周报」，即按本约定产出，并回报一句摘要；如用户给定了更早/更晚的截止点，以用户指定为准。
